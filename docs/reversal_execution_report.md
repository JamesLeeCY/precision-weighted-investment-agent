# 用短期反轉降低財報組合的交易成本

| | |
|---|---|
| 日期 | 2026-10-10 |
| 股票池 | 無選股偏誤股票池（`config/tickers_pit.yaml`） |
| 方法 | 財報產業中性做多，每 21 個交易日換倉、持有 20 日；21 種取樣起點中位數；扣成本（換手量 × 單邊 0.29625%） |
| 數字 | [reversal_execution_data.md](reversal_execution_data.md)（`analysis/reversal_execution.py` 自動產生） |

## 動機

[短期反轉報告](short_term_reversal_report.md)發現反轉是真的，但單獨交易時換手太高、扣成本後虧損。
這裡改成**不另外交易**，只在財報組合原本就要換倉時，用反轉改變取捨（設計在看結果前固定）：

- **B 延後賣出**：原本要賣出的持股，若近 5 日跌幅在產業內後 1/3（反轉訊號前 1/3），本期續抱，避免賣在短期低點。
- **C 邊際偏好跌深**：選股分數 = 財報產業內百分位 + 0.1 × 反轉產業內百分位。產業約 38 檔時，最多讓名單邊緣前後移動 3–4 名。
- 反轉訊號用過去 5 日報酬的負值（前一個交易日以前的資料）。5 日在上一批兩段都為正；10 日樣本外最好但 2023 年後轉負，選它等於事後挑選。
- 兩個基準：產業中性前 1/3、加緩衝（已持有者產業內百分位 > 50% 就續抱）。

## 結果

| 組合 | 超額 2019–2022（樣本外） | t | 2023–2026 | 每期換手 | 平均持股 | Sharpe 2019–2022 / 2023–2026 | 最大回撤 2019–2022 |
|---|---|---|---|---|---|---|---|
| 基準：產業中性做多 | +0.13%（19/21） | 0.52 | +0.47% | 0.58 | 35.8 | 0.57 / 1.80 | −40% |
| + B 延後賣出 | +0.16%（21/21） | 0.69 | +0.47% | 0.52 | 40.0 | 0.58 / 1.83 | −41% |
| + C 邊際偏好跌深 | +0.13%（16/21） | 0.50 | +0.44% | 0.59 | 35.9 | 0.56 / 1.76 | −40% |
| + B + C | +0.16%（20/21） | 0.69 | +0.47% | 0.54 | 39.8 | 0.58 / 1.80 | −40% |
| 基準：產業中性 + 緩衝 | **+0.25%**（21/21） | 1.14 | +0.49% | 0.42 | 43.5 | 0.63 / 1.81 | −40% |
| 緩衝 + B | +0.25%（21/21） | 1.15 | +0.48% | **0.37** | 47.1 | 0.64 / 1.83 | −40% |
| 緩衝 + C | +0.26%（21/21） | 1.16 | +0.49% | 0.42 | 43.7 | 0.62 / 1.82 | −40% |
| 緩衝 + B + C | +0.24%（21/21） | 1.18 | +0.53% | 0.38 | 47.3 | 0.63 / 1.86 | −40% |
| 對照：0050 買進持有 | — | — | — | — | — | **0.72 / 2.09** | −29% |

超額為相對等權持有、扣成本、每期（20 個交易日）平均；括號為 21 起點中為正的數目。

## 解讀

1. **延後賣出（B）讓換手降低約 10%**（0.58 → 0.52；有緩衝時 0.42 → 0.37），沒有緩衝時樣本外超額小幅提高（+0.13% → +0.16%，
   21/21 起點為正）；有緩衝時超額不變。Sharpe 幾乎沒有變化（±0.01–0.03）。
   延後賣出省下的成本，大致被「多抱一檔財報排名已轉弱的股票 20 天」抵銷：反轉只持續約 5 天，持有期卻是 20 天。
2. **邊際偏好跌深（C）沒有效果**：超額持平或略降，換手不變。反轉訊號對 20 日報酬的預測力太弱，改變名單邊緣的幾檔沒有差別。
3. **真正降低成本的是緩衝規則**（換手 0.58 → 0.42，樣本外超額 +0.13% → +0.25%，Sharpe 0.57 → 0.63）。
   但緩衝是在[產業中性組合報告](sector_neutral_report.md)看過結果後才加的（事後調整），這裡的樣本外數字仍偏樂觀。
4. **所有組合的 Sharpe 都低於 0050**（樣本外 0.56–0.64 vs 0.72；2023–2026 1.76–1.86 vs 2.09），最大回撤也都比 0050 深。

## 結論

- 短期反轉用在換倉時機上，能**小幅降低換手**，但**不能提高 Sharpe**，也不足以讓組合贏過 0050。
- 不採用 C；B 可視為降低換手的可選細節（效果在兩段都非負），但不影響結論。
- 到目前為止，在這個股票池能得到的最好結果仍是「財報產業中性 + 緩衝」：樣本外相對等權每期 +0.25%（t 1.1），
  Sharpe 0.63，低於 0050 的 0.72。要贏過大盤需要更強的選股訊號，交易執行面的改善空間有限。

本批共 8 種組合（2 個基準 × 4 種反轉用法）。
