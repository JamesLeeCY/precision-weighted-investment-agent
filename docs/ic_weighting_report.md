# 產業內 IC 加權合併報告

| | |
|---|---|
| 執行日期 | 2026-10-09 |
| 動機 | [無選股偏誤股票池報告](pit_universe_report.md)：只有財報 Agent 有產業內排序能力；精度加權以 Brier 衡量，各 Agent 都接近 0.25、分辨不出誰會排序，合併反而稀釋了財報 Agent |
| 實作 | [arbitrator/ic_weighting.py](../arbitrator/ic_weighting.py)；回測新增策略「產業內 IC 加權」（`ic_weighted`） |
| 輸出 | [reports/finmind_pit/](../reports/finmind_pit/comparison_report.md)（3 Agent，含新策略）、[reports/finmind_pit_fundamentals/](../reports/finmind_pit_fundamentals/comparison_report.md)（只放財報 Agent） |
| 執行時間 | 兩組回測合計約 6 分鐘（資料全部已快取，不需 FinMind API） |

## 結論先講

1. **IC 加權修正了合併的稀釋問題**：3 Agent 合併相對等權持有從每期 −0.44% 變成 **+0.30%**，自動把總經與供應鏈 Agent 的權重壓到接近 0。
2. **但沒有勝過「直接只用財報 Agent」**（+0.26%，t 1.90，且 t 值更高）。原因是 IC 的估計雜訊：每期 IC 的標準差（0.122）是平均值（0.029）的 4 倍，24 期的滾動估計標準誤就有 ±0.025，回測初期的權重主要是在追雜訊。
3. **建議以固定組成為預設**（只放財報 Agent），IC 加權作為監控工具，而不是主要的合併方式。

## 1. 方法

每個預測時點，只用**已到期**（resolution_date ≤ 當下）的預測：

- 對每個 Agent 計算最近 24 個已到期時點的產業內 IC：各時點在各產業內做 Spearman(看多機率, 20 日含息報酬)，以股票數加權平均。
- 權重 w = max(0, 平均產業內 IC)；不足 6 個時點時各 Agent 等權（冷啟動）。
- 合併機率 = 以 w 加權的看多機率平均；全部權重為 0 時為 0.5（中性）。
- **純產業押注不算產業內能力**：若 Agent 在產業內沒有差異，該時點的產業內 IC 記為缺值，不會因為押對產業而得到權重。只有在股票池太小、沒有任何產業有 3 檔以上時，才退回全體排序。（測試抓到第一版會把產業押注誤算進來，已修正。）
- 參數（24 期、6 期）事先固定。使用 Agent 的原始連續機率（校準後的機率被收縮到 0.5 附近，幾乎不產生訊號）。

## 2. 權重如何演變（3 Agent）

| 年份 | 財報 | 總經/籌碼 | 供應鏈 | 財報權重占比 |
|---|---|---|---|---|
| 2019 | 0.500 | 0.500 | 0.508 | 17%（冷啟動，等權） |
| 2020 | 0.000 | 0.000 | 0.021 | **2%** |
| 2021 | 0.039 | 0.007 | 0.021 | 59% |
| 2022 | 0.046 | 0.004 | 0.011 | 80% |
| 2023 | 0.017 | 0.000 | 0.000 | 100% |
| 2024 | 0.022 | 0.001 | 0.000 | 97% |
| 2025 | 0.036 | 0.001 | 0.000 | 99% |
| 2026 | 0.044 | 0.001 | 0.000 | 99% |

2023 年後幾乎全部權重都在財報 Agent，符合預期；但 2020 年在歷史資料很少時，權重一度幾乎全給了供應鏈 Agent——這是雜訊，不是能力。

## 3. 結果（271 檔 × 2019–2026，扣交易成本）

| 策略 | 產業內 IC | 每期超額 vs 等權持有 | 2019–2023 | 2024–2026 | 平均持股 |
|---|---|---|---|---|---|
| 財報 Agent 單獨（p > 0.5） | **+0.029（t 2.16）** | **+0.26%（t 1.90）** | +0.24% | +0.31% | 58 |
| 3 Agent 簡單平均 | +0.019（t 1.56） | −0.44%（t −0.97） | −0.76% | +0.24% | 23 |
| **3 Agent 產業內 IC 加權** | +0.020（t 1.51） | **+0.30%（t 1.09）** | +0.39% | +0.13% | 37 |
| 只放財報 Agent 的合併（p > 0.55） | +0.029（t 2.16） | +0.28%（t 1.26） | +0.33% | +0.18% | 37 |
| 只放財報 Agent + IC 加權 | +0.028 | −0.17%（t −0.37） | −0.33% | +0.18% | 31 |

| | 累積報酬 |
|---|---|
| 財報 Agent 單獨 | +678.5% |
| 3 Agent 產業內 IC 加權 | +665.2% |
| 3 Agent 簡單平均 | +307.2% |
| 等權持有本股票池 | +537.9% |
| 0050 | +566.1% |

解讀：

- **IC 加權的價值在於「排除沒用的 Agent」**：3 Agent 合併從 −0.44% 回到 +0.30%，累積報酬從 +307% 回到 +665%，接近財報 Agent 單獨的水準。
- **它沒有額外的好處**：產業內 IC（+0.020）低於財報 Agent 單獨（+0.029），因為 2019–2021 的權重受雜訊影響。
- **只有一個 Agent 時，IC 加權會變成擇時開關**：權重被歸零時整期空手。財報 Agent 的歷史 IC 在資料還很少的 2019 年中到 2020 年底為負，權重歸零共 16 期，因而錯過這段行情（−0.17%）；之後全期的 IC 其實為正。這又是同一個估計雜訊的問題。
- 「只放財報 Agent」的合併版本（門檻 0.55，持股 37 檔）與財報 Agent 單獨（門檻 0.5，持股 58 檔）的超額相近；持股較集中、波動較大，因此 t 值較低。

## 4. 為什麼自適應權重難以奏效

| 財報 Agent 產業內 IC（每期） | |
|---|---|
| 平均 | +0.029 |
| 標準差 | 0.122 |
| 24 期平均的標準誤 | 0.025 |
| 平均 IC 要達到 t = 2 需要的期數 | 約 73 期（約 6 年） |

訊號只有雜訊的四分之一。用 2 年資料估計「誰有能力」，估計誤差和訊號一樣大；要 6 年才能可靠地確認。這也解釋了先前以 Brier 為基礎的精度加權為什麼從未勝過簡單平均：所有「依歷史表現調整權重」的機制，在訊號這麼弱時都主要在追雜訊。

## 5. 建議

1. **預設合併組成改為只放財報 Agent**（`--agents fundamentals_agent`），依據是 2019–2026 全期、獨立股票池上的證據，而不是滾動估計。
2. **產業內 IC 加權保留為監控工具**：持續記錄各 Agent 的產業內 IC，用來發現新 Agent 是否開始有用、或財報 Agent 是否失效；若要用於權重，應加上強先驗（例如向固定組成收縮）並使用更長的估計期間。
3. **前瞻驗證仍是下一步**：凍結規則與參數，從 2026-06 起逐月記錄。
