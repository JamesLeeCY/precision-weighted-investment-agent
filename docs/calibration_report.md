# Agent 層級重新校準報告

| | |
|---|---|
| 執行日期 | 2026-10-07 |
| 實作 | [arbitrator/calibration.py](../arbitrator/calibration.py)，整合於 `backtest/run_backtest.py:run_walk_forward` |
| 資料 | 同 135 個事件；規則式 2 Agent / 3 Agent、LLM（qwen3:8b，使用已快取回應）；synthetic 5 檔 × 100 時點 |
| 新增策略 | 校準後簡單平均、校準後精度加權（原三個策略保留不變） |

## 1. 方法

**校準函數**：每個 Agent 一個收縮係數 a ∈ [0, 1]

  p' = σ(a · logit(p))

- a = 1 不修正；a = 0 代表毫無判讀能力，p' 一律為 0.5
- neutral（p = 0.5）校準後仍為 0.5；a ≥ 0 保證訊號方向不翻轉
- 只收縮不放大：本專案的問題是過度自信，樣本少時放大風險高

**擬合**：
- walk-forward，只用已到期的判斷；每個 Agent 跨 5 檔股票合併成一個樣本池
- 最大概似 + 往 a = 1 的二次先驗（強度 2.0），累積滿 10 筆才開始校準
- 以 [0, 1] 網格搜尋求解
- 超參數事先固定，**沒有**依回測結果調整

**校準後精度**：依[技術筆記](technical_note.md)第 6 節，精度改以「預測當下的校準後機率」的 Brier 累積，讓精度只反映資訊量、不含校準誤差。

## 2. 結果：機率品質

| 策略 | 規則式 2 Agent | 規則式 3 Agent | LLM（qwen3:8b） |
|---|---|---|---|
| 簡單平均 | 0.2556 | **0.2538** | 0.2805 |
| 精度加權 | 0.2557 | 0.2540 | 0.2812 |
| 校準後簡單平均 | **0.2549** | 0.2543 | 0.2552 |
| 校準後精度加權 | **0.2549** | 0.2545 | **0.2548** |

（數字為平均 Brier，越低越好；無資訊基準 0.25）

| 策略 | 規則式 2 Agent ECE | 規則式 3 Agent ECE | LLM ECE |
|---|---|---|---|
| 簡單平均 | 0.061 | 0.054 | 0.131 |
| 校準後簡單平均 | **0.040** | **0.049** | **0.095** |
| 校準後精度加權 | **0.040** | 0.057 | **0.080** |

個別 Agent（LLM 判讀）：

| Agent | 原始 Brier | 校準後 Brier | 期末收縮係數 a |
|---|---|---|---|
| 財報 | 0.3354 | 0.2644 | 0.09 |
| 新聞 | 0.2718 | 0.2600 | 0.18 |
| 總經/籌碼 | 0.4047 | 0.2664 | **0.00** |

規則式 Agent 的期末係數：財報 0.41、新聞 0.64、總經 0.78。

**解讀：**

1. **校準大幅修正了 LLM 的過度自信**：合併 Brier 從 0.2805 降到 0.2548，回到規則式的水準。期末係數 0.00–0.18，代表 LLM 的信心幾乎全部收回 0.5，總經 Agent 被判定為毫無判讀能力。
2. **ECE 在所有設定下都改善**（LLM 0.131 → 0.080）。
3. **但沒有任何設定低於 0.25**：校準只能把壞的機率修到「沒有害處」，無法無中生有。校準後的 LLM（0.2548）也沒有勝過規則式（0.2538）。
4. 規則式 3 Agent 校準後 Brier 略升（0.2538 → 0.2543）：校準初期樣本少、係數估計有雜訊，在沒什麼過度自信可修的情況下，雜訊的成本大於收益。

## 3. 核心發現：LLM 的「精度分化」其實是校準誤差

| 股票 | LLM 原始精度比（最大/最小） | **校準後精度比** |
|---|---|---|
| 2327 | 1.76 | 1.08 |
| 2375 | 2.63 | 1.28 |
| 2478 | 1.54 | 1.04 |
| 2492 | 1.35 | 1.06 |
| 3026 | 2.37 | 1.11 |

LLM 實驗中看到的精度分化（1.35–2.63），在校準後縮回 1.04–1.28，和規則式 Agent 一樣窄。

這表示**原本的分化主要來自「各 Agent 過度自信的程度不同」，而不是「各 Agent 擁有的資訊量不同」**。把過度自信修掉之後，三個 LLM Agent 一樣沒有判讀能力，精度加權自然無從分辨。這正是技術筆記第 6 節預期的區分：precision 應該反映資訊量，而不是校準誤差。

## 4. Synthetic 驗證（20 seeds）

synthetic 情境中，財報 Agent 校準良好，新聞 Agent 刻意過度自信 0.15，兩者都真的有判讀能力。

| 策略 | 平均 Brier（20 seeds） |
|---|---|
| 單一 Agent（財報） | 0.2194 |
| 簡單平均 | 0.2221 |
| 精度加權 | 0.2213 |
| 校準後簡單平均 | 0.2220 |
| 校準後精度加權 | 0.2216 |

- 新聞 Agent 校準後 Brier 改善：**20/20 seeds**（0.2555 → 0.2472），校準機制有效。
- 校準後精度加權勝過校準後簡單平均：16/20 seeds；原本精度加權勝過簡單平均：17/20（重現技術筆記第 3 節）。
- **校準後精度加權勝過原始精度加權：只有 9/20**，合併後沒有整體增益。

**為什麼每個 Agent 都變好，合併卻沒有變好？** 這符合文獻的已知性質：把各自已校準的機率做線性平均，結果會偏向保守、信心不足（Ranjan & Gneiting, 2010）。校準把各 Agent 拉向 0.5，平均之後又再被拉一次。要真正受益，需要在**合併後**再校準一次，或改用對數意見池（技術筆記第 6 節）。

## 5. 報酬層級：校準修正了機率，沒修正投票

| 策略（LLM 判讀） | 累積報酬 | 持股期比例 | 每期超額 vs 0050 t |
|---|---|---|---|
| 簡單平均 | −11.3% | 33% | −3.73 |
| 校準後簡單平均 | −15.4% | 48% | −3.95 |
| 校準後精度加權 | −8.3% | 48% | −3.63 |
| 0050 | +191.7% | 100% | — |

規則式 3 Agent 的四個合併策略訊號完全相同，組合報酬都是 +182.2%。

組合報酬幾乎沒改善，原因在規格 5.2 的訊號公式：

  final_score = Σ(precision · confidence · s) / Σ(precision · confidence)

- confidence 下限是 0.5，所以即使總經 Agent 被校準到 a = 0（p' = 0.5，代表「毫無把握」），它的看空票 s = −1 仍以 0.5 的權重計入，繼續把訊號拖向空手。
- 合併機率（Brier 用的）會反映校準，合併訊號（組合用的）卻不會，兩者不一致。

**待決策**：讓訊號也反映校準，例如權重改用「確信度」2·confidence − 1（confidence 0.5 時權重為 0），或直接由合併機率決定訊號。這會改變規格 5.2 與所有歷史訊號，因此先記錄、不實作。

## 6. 結論

1. **校準有效，但只能止損**：它把 LLM 的過度自信修回無害的水準（Brier 0.2805 → 0.2548，ECE 0.131 → 0.080），但沒有任何設定能低於 0.25。
2. **LLM 的精度分化是假象**：校準後精度比回到 1.04–1.28。目前三個 Agent（規則式或 LLM）都沒有真正的資訊量差異，這才是精度加權無法發揮的根本原因。
3. **線性意見池 + 個別校準會信心不足**：synthetic 中個別 Agent 都變好，合併卻沒有變好。
4. **訊號公式沒有跟著校準**：組合報酬的改善需要先處理第 5 節的規格問題。

## 7. 下一步

1. **決定規格 5.2 的訊號權重**（第 5 節）：改用 2·confidence − 1 或由合併機率決定訊號。
2. **合併後再校準，或改用對數意見池**：解決第 4 節的信心不足問題。
3. **提升 Agent 本身的資訊量**：目前瓶頸在 Agent 沒有判讀能力，而不是合併機制。可考慮的方向：更強的 LLM、思考模式、新聞內文（目前只有標題）、供應鏈 Agent。

## 8. 訊號公式修訂（2026-10-07）

依第 5 節的待決事項，使用者決策採用：投票權重改為確信度 κ = |2p − 1|，分母為 Σprecision，即

  final_score = Σ(precision · κ · s) / Σprecision = 2·p − 1，p = Σ(precision · p_i) / Σprecision

訊號門檻改為 ±0.1（合併機率 > 0.55 看多、< 0.45 看空），事先設定、不依回測調整（`arbitrator/merge.py`）。修訂後：
- 機率 p = 0.5 的 Agent 不再投票，被校準到 a = 0 的 Agent 不會左右訊號。
- 合併訊號與合併機率完全一致。
- 只有一個 Agent 表態時，極小的確信度不會被放大成強訊號。

**以上第 2–5 節是修訂前的數字。** 修訂後重跑的結果：

| 策略 | 規則式 2 Agent Brier | 規則式 3 Agent Brier | LLM Brier | 規則式 3 Agent 累積報酬 | LLM 累積報酬 |
|---|---|---|---|---|---|
| 單一 Agent（財報） | 0.2593 | 0.2593 | 0.3354 | +22.8% | +8.3% |
| 簡單平均 | 0.2540 | **0.2530** | 0.2726 | −23.2% | −25.0% |
| 精度加權 | 0.2542 | 0.2532 | 0.2733 | −18.6% | −24.4% |
| 校準後簡單平均 | **0.2538** | 0.2535 | 0.2547 | −12.3% | −22.1% |
| 校準後精度加權 | 0.2539 | 0.2536 | **0.2544** | −12.3% | −20.1% |
| 0050 | — | — | — | +191.7% | +191.7% |

**解讀：**

1. **機率品質小幅改善**：規則式 3 Agent 簡單平均 Brier 0.2538 → 0.2530，是目前最好的成績，但仍高於 0.25。
2. **組合報酬大幅反轉**：規則式 3 Agent 的合併策略從 +182.2% 變成 −12% 到 −23%。新公式下看多訊號變少，持股期從 93% 降到 30–56%，在 0050 年化 +61% 的多頭中錯過漲幅。
3. **系統表態時反而常錯**：規則式 3 Agent 合併策略只在約 14–30 個事件表態，方向準確率約 43%（樣本少，未達顯著）。
4. 這證實第 6 節與 Phase 2 報告的判斷：**之前的 +182% 來自「多頭中多數時間持股」，不是訊號的判讀能力**。換一個合理的訊號公式，報酬就整個翻轉。

**Synthetic（20 seeds）與代價：**

| 比較 | 修訂前 | 修訂後 |
|---|---|---|
| 精度加權 < 簡單平均 | 17/20 | 17/20 |
| 校準後精度加權 < 校準後簡單平均 | 16/20 | **18/20** |
| 合併（簡單平均）< 單一 Agent | — | **2/20** |
| 精度加權平均 Brier | 0.2213 | 0.2229 |

精度加權機制仍然成立，但修訂後的合併機率會被中性輸出稀釋。新的合併機率是純精度加權平均，表態中性（p = 0.5）的 Agent 也以完整精度權重納入；舊公式的權重是精度 × 信心，沒有資訊時的中性輸出（信心 0.3）權重較低。在 synthetic 裡，每個 Agent 只有 60% 的時間有資訊，稀釋使合併結果信心不足。真實資料中 Agent 本來就沒有判讀能力，被拉向 0.5 反而讓 Brier 略降。

**後續選項**：讓中性 Agent 棄權（不進入平均）；或改用對數意見池，中性輸出的 logit 為 0，天然不影響結果。
