# 降低等權多空的換手：換倉頻率與持有緩衝（2026-10-13）

接續 [等權多空與可借量](borrow_capacity_report.md)。月營收驚奇（SUE）等權多空在可借限制下（資金 2 億）每月換倉的 Sharpe 為 0.48 / 1.16，
但年換手 21 倍、交易成本約 6%／年。這裡測試降低換手的兩種方式。
完整自動產生的表格見 [ls_turnover_top300.md](ls_turnover_top300.md)。研究結果，非投資建議。

## 設計（看結果前固定）

- **換倉頻率**：每 1、2、3 個月換倉一次；只在第 1、1+k、1+2k… 個月營收公告後換倉日調整，中間不動。
- **緩衝**：
  - 新進場只從產業內前 1/3（做多）或後 1/3（放空）。
  - 已持有的多單只要仍在前 1/2 就續抱。
  - 已持有的空單只要仍在後 1/2、且仍借得到就續抱。
- **其他條件不變**：
  - 放空只用可借股票（資金 2 億、條件 D）。
  - 剩餘 β 以台指期對沖。
  - 扣交易成本（兩邊換手 × 0.29625%）與實際借券費。
  - 需借股數以「當日平均放空權重」估計。
- **版本數**：共 6 個版本；另列 2 個不限制可借的版本作參考。

## 結論

1. **降低換手明顯改善淨績效，而且兩段一致**：
   - 每 3 個月換倉讓換手從 21 倍降到 9 倍，交易成本從 6.3% 降到 2.7%／年；
   - Sharpe 從 0.49 / 1.16 升到 0.79 / 1.85，兩段都提高；
   - 8 年中只有 2019 年為負，原版 2019、2024 兩年為負。
2. 這和先前研究一致：SUE 的預測力可延續 60 日以上，60 日 IC 大於 20 日（[revenue_surprise_report.md](revenue_surprise_report.md)）。每月換倉付出的成本，換到的資訊增量很小。
3. **緩衝主要降低回撤與換手**（每 3 個月 + 緩衝：回撤 −8.9%、換手 7.1 倍），Sharpe 與無緩衝相當，兩段互有高低。
4. **注意**：
   - 先前在 SUE 做多組合上已看過「每 3 個月換倉」的結果，這裡不完全是事先未知的設定。
   - 每 3 個月換倉的結果也取決於從哪個月開始換，換倉起點的穩健性尚未檢查。
   - 6 個版本的多重比較也應打折看待。

## 可能的下一步

- 檢查換倉起點的穩健性：每 3 個月換倉可從第 1、2、3 個換倉日開始，共 3 種起點。
- 若穩健，可另立「SUE 等權多空、每 3 個月換倉、限制可借」的前瞻規格。
