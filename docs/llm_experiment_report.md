## 1. 實驗目的

Phase 1、2 的三個規則式 Agent 可靠度太接近（精度比 ≤ 1.24），精度加權無從發揮。這個實驗要驗證：改用 LLM 判讀能否讓各 Agent 的可靠度分化，以及分化後精度加權是否勝過簡單平均。

## 2. 結果

| 策略 | 規則式 Brier | **LLM Brier** | 規則式 ECE | **LLM ECE** |
|---|---|---|---|---|
| 單一 Agent（財報） | 0.2593 | **0.3354** | 0.117 | **0.286** |
| 簡單平均（3 Agent） | 0.2538 | **0.2805** | 0.054 | **0.131** |
| 精度加權（3 Agent） | 0.2540 | **0.2812** | 0.059 | **0.157** |

個別 Agent：

| Agent | 規則式 Brier | LLM Brier | LLM 訊號分布（多/空/中性） | 有方向訊號命中率 | 信心 ≥ 0.8 的命中率 |
|---|---|---|---|---|---|
| 財報 | 0.2593 | 0.3354 | 46% / 30% / 24% | 50% | 50%（86 筆） |
| 新聞 | 0.2531 | 0.2718 | 45% / 5% / 50% | **56%** | 53%（32 筆） |
| 總經/籌碼 | 0.2547 | **0.4047** | **0% / 100% / 0%** | 45% | 45%（130 筆） |

**LLM 判讀全面劣於規則式。** 主因是嚴重過度自信：三個 Agent 大多數訊號的信心都 ≥ 0.8，實際命中率卻只有 45–53%，接近擲硬幣。

## 3. 總經 Agent 的系統性看空偏誤

總經/籌碼 Agent 在 135 個事件中**全部判斷看空**，規則式判為看多的 23 次也全被改判看空。從 rationale 看，模型不論數字正負都解讀成利空，例如：

- 「美債殖利率**下跌**……偏空」
- 「融資餘額**下降**顯示散戶拋壓」（system prompt 已說明融資是反向指標）
- 「外資持股增加與投信買超顯示資金流入，但……整體偏向 bearish」

prompt 中每個特徵都附有中文定義與正負號意義，所以這不是資料或欄位誤讀的問題，而是 8B 模型在關閉思考模式下的推理偏誤。

## 4. 精度確實拉開了，但精度加權沒有變好

| 股票 | 財報 | 新聞 | 總經 | 最大/最小 |
|---|---|---|---|---|
| 2327 | 2.59 | 3.92 | 2.23 | 1.76 |
| 2375 | 1.57 | 4.13 | 3.38 | 2.63 |
| 2478 | 2.85 | 3.85 | 2.51 | 1.54 |
| 2492 | 2.68 | 2.84 | 3.63 | 1.35 |
| 3026 | 2.66 | 4.27 | 1.80 | 2.37 |

- **分化出現了**：精度比從規則式的 ≤ 1.24 拉大到 1.35–2.63，新聞 Agent 在 4 檔中精度最高，與它全期 Brier 最好一致。精度加權與簡單平均的合併機率平均差 0.038、最大差 0.21，有 31 個事件訊號不同。
- **但精度加權仍略輸簡單平均**（Brier 0.2812 vs 0.2805）。原因：
  1. 三個 Agent 都比無資訊基準差，精度只是「挑出最不差的」，沒有好的來源可以加重。
  2. 精度 = 1/(Brier EMA + 0.01) 的判別力溫和，壓不住 Brier 0.40 的總經 Agent。
  3. EMA（α = 0.2）有效記憶約 5 筆，權重跟著近期雜訊擺動。
- 這正對應[技術筆記](technical_note.md)第 4 節的分析：線性意見池會繼承過度自信來源的偏差，**合併前需要先在 Agent 層級重新校準**。

## 5. 報酬層級

| 策略 | 累積報酬 | 持股期比例 | 每期超額 vs 0050 t | 橫斷面 IC（t） |
|---|---|---|---|---|
| 單一 Agent（財報，LLM） | +8.3% | 78% | −2.25 | −0.061（−0.55） |
| 簡單平均（LLM） | −11.3% | 33% | **−3.73** | +0.101（0.99） |
| 精度加權（LLM） | −15.6% | 48% | **−3.84** | +0.037（0.43） |
| 合併（規則式，對照） | +182.2% | 93% | +0.16 | −0.147（−1.26） |
| 0050 | +191.7% | 100% | — | — |

總經 Agent 一律看空，把合併訊號拖向空手。在 0050 年化 +61% 的多頭期間，持股期只剩 33–48%，組合虧損並顯著輸給 0050。橫斷面 IC 轉為小幅正值，但不顯著。

## 6. 結論

1. **前提成立、結果不成立**：LLM 判讀確實讓 Agent 的可靠度分化（精度比最高 2.6），但分化來自「有的 Agent 很差」，而不是「有的 Agent 很好」。精度加權沒有好來源可以加重。
2. **地端 8B 模型直接輸出的 confidence 不可用**：嚴重過度自信，且總經判讀有系統性方向偏誤。
3. 新聞 Agent 是唯一勉強有用的 LLM 判讀：方向命中率 56%、IC 小幅正值，但仍因過度自信而 Brier 劣於規則式。

## 7. 下一步

1. **Agent 層級重新校準**（最優先，不需重跑 LLM）：以 walk-forward 方式，只用已到期的預測，對每個 Agent 擬合「原始機率 → 實際命中率」的校準函數（Platt / isotonic / 收縮到 0.5），再進入合併。直接修正本實驗暴露的過度自信，且可沿用已快取的 386 筆回應。
2. **開啟 qwen3 思考模式重跑總經 Agent**：檢驗方向偏誤能否靠推理修正；預估耗時是目前的數倍。
3. 若換用更強的模型（例如雲端 Claude），同一套管線只需改 `--llm-provider anthropic`。
