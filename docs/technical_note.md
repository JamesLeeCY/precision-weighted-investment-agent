# 技術筆記：精度加權信念更新在多智能體投資研究系統中的實作與驗證

（規格 M5 交付物，2026-07-03）

## 1. 理論對應：預測處理框架 → 仲裁層設計

神經科學的預測處理框架（predictive processing）主張，大腦整合多個訊號來源時
並非等權平均，而是以各來源的 **precision**（預測誤差變異數的倒數）加權：
可靠的來源獲得更大的信念更新權重，且 precision 本身隨經驗持續更新。

本系統的對應關係：

| 預測處理框架 | 本系統實作 |
|---|---|
| 訊號來源（感覺通道） | 專家 Agent（財報、新聞事件） |
| 單次預測誤差 | 單次 Brier score：(p − o)²，p 為規格 6.1 之機率轉換 |
| 預測誤差變異數的估計 | Brier score 的指數移動平均（EMA，α = 0.2） |
| precision（變異數倒數） | precision = 1 / (brier_ema + 0.01) |
| precision 加權信念更新 | final_score = Σ(precision·κ·s) / Σprecision，κ = \|2p − 1\|（2026-10-07 修訂；原為 Σ(precision·confidence·s) / Σ(precision·confidence)） |
| loose → tight coupling | 冷啟動（n < 5 時取全體均值 → 均等權重）→ 隨記錄累積收斂至可靠 Agent 主導 |

兩個量的區分（規格 3.1 強調）：`confidence` 是 Agent 對**單次**判斷的主觀信心
（likelihood 的銳利度）；`precision` 是仲裁層對該 Agent **歷史**可靠度的估計。
合併公式將兩者相乘作為權重，等同於「這次訊號有多強 × 這個來源多可信」。

## 2. 實作要點與規格詮釋

1. **合併機率的定義**：規格 5.2 只定義了 final_score 與訊號閾值（±0.3），
   未定義合併輸出的機率形式（系統層級 Brier 需要機率）。本實作採
   **精度加權線性意見池**：p = Σ(wᵢ·pᵢ) / Σ(wᵢ)，其中 wᵢ = precisionᵢ·confidenceᵢ
   與規格 5.2 同權重，pᵢ 為規格 6.1 之個別機率。相較於 (final_score+1)/2 的
   映射，意見池避免「兩個 Agent 同向時機率被推到 0/1 極端」的過度自信問題
   （實驗中後者使合併策略 Brier 顯著劣化）。
   **2026-10-07 修訂**：投票權重改為 precision·κ（κ = |2p − 1| 為確信度），分母改為
   Σprecision，合併機率改為 p = Σ(precisionᵢ·pᵢ)/Σprecision，恆有 final_score = 2p − 1，
   門檻改為 ±0.1（p 為 0.55 / 0.45）。原因是有方向訊號的 confidence 下限為 0.5，
   原公式讓「毫無把握」的 Agent 仍以 0.5 權重投票，Agent 層級校準因此無法反映到
   訊號上。詳見[校準報告第 8 節](calibration_report.md#8-訊號公式修訂2026-10-07)。
2. **uncertainty 公式**：規格 5.2 的文字（「越接近 1 代表越依賴單一來源」）與
   公式 `1 − max(precision)/Σprecision` 方向相反。依同節前句「precision 越集中
   在少數高權重 Agent，區間應越窄」，以公式為準：精度集中 → uncertainty 低。
3. **冷啟動層級**：規格 5.1 要求 n < 5 時取「所有已知 Agent 精度的平均值」。
   實作上優先取同 ticker 的成熟記錄均值，其次全體成熟記錄，完全無歷史時
   所有 Agent 共享同一預設值（= 1/(0.25+ε)，0.25 為「永遠猜 0.5」的 Brier），
   即嚴格的均等權重起點。
4. **走時序回測**：精度更新只發生在 horizon 已到期（resolution_date ≤ 當前
   as_of_date）的預測上，確保精度快照不含未來資訊；財報資料另設公告遞延
   （月營收 40 天、季報 75 天）避免 look-ahead。

## 3. 實驗結果（synthetic 模式，機制驗證）

情境設計：兩個 Agent 資訊互補（各只有 60% 時點有資訊，否則輸出 neutral）；
fundamentals_agent 校準良好（命中率 = confidence），news_agent 系統性過度自信
（命中率 = confidence − 0.15）。5 檔股票 × 100 個時點 = 500 筆預測/策略。

**20 個隨機 seed 的穩健性統計：**

| 策略 | 平均 Brier (±SD) | 方向準確率 | 平均 ECE |
|---|---|---|---|
| Baseline A：單一 Agent（財報） | 0.2194 ± 0.0076 | 0.709 | 0.0449 |
| Baseline B：簡單平均合併 | 0.2221 ± 0.0073 | 0.674 | 0.0437 |
| 本系統：精度加權合併 | 0.2213 ± 0.0074 | 0.673 | 0.0443 |

- 精度加權 Brier 優於簡單平均：**17/20 seeds**（paired 改善 +0.0008 ± 0.0010）
- 精度加權 Brier 優於單一 Agent：6/20 seeds
- 精度加權 ECE ≤ 簡單平均：9/20 seeds（大致持平）

## 4. 誠實分析（規格 6.3：未全數達標時需記錄原因）

**通過的部分**：精度加權 vs 簡單平均是本機制的直接 ablation——同樣的 Agent
輸出、同樣的合併公式，唯一差異是權重來源。17/20 seeds 的一致方向改善顯示
精度追蹤確實把權重移向可靠來源（回測結束時 fundamentals_agent 的 precision
穩定高於 news_agent）。

**未通過的部分與原因**：整體 ensemble 的 Brier 未穩定勝過單一校準良好的
Agent（6/20）。三個原因：

1. **線性意見池的校準極限**：線性混合一個校準良好與一個過度自信的機率來源，
   除非後者權重趨近 0，混合結果必然繼承部分過度自信。而
   precision = 1/(brier_ema + ε) 是溫和的判別器——本情境中兩 Agent 的
   precision 比僅約 1.3–1.6：1，不足以完全壓制劣質來源。
2. **冷啟動成本**：每檔股票前 5 筆預測強制均等權重，這段期間精度加權
   完全等同簡單平均，稀釋了可測得的差異。
3. **EMA 收斂速度**：α = 0.2 意味著精度估計的有效記憶約 5 筆，估計本身
   帶有變異數，權重因此在最適值附近抖動。

**對真實資料回測（finmind 模式）的預期**：真實世界中兩個 Agent 的資訊來源
（財報 vs 新聞）互補性更強、可靠度差距可能更大，精度加權的相對優勢應更明顯；
此假設留待填入 `FINMIND_API_TOKEN` 後以 `--mode finmind` 驗證。

## 5. 真實資料回測（FinMind，2026-07-03 縮小版）

範圍：國巨 2327 / 華新科 2492 / 禾伸堂 3026，2025-01 ~ 2026-05，
每 21 個交易日一個預測點，共 47 個事件（兩 Agent 皆為規則式判斷，無 LLM）。

| 策略 | Brier ↓ | 方向準確率 | ECE ↓ |
|---|---|---|---|
| Baseline A：單一 Agent（財報） | 0.2553 | 0.524 | 0.1490 |
| Baseline B：簡單平均合併 | **0.2529** | 0.517 | **0.0848** |
| 本系統：精度加權合併 | 0.2532 | 0.517 | 0.1103 |

觀察：

1. **合併優於單一 Agent**（Brier 與 ECE 皆是）——ensemble 分散效果在真實
   資料上成立。
2. **精度加權 ≈ 簡單平均**：回測結束時兩個 Agent 的 brier_ema 皆落在
   0.24–0.30 的窄帶，同 ticker 的精度比僅 1.08–1.13，全部 47 個事件中
   兩策略的合併機率分歧皆 < 0.01。這不是機制失效——當來源實際可靠度
   相近時，精度加權**理論上就應該**收斂到等權（loose coupling 是均衡解）；
   精度加權的價值只在來源可靠度確實分化時才會顯現（見 synthetic 實驗）。
3. 方向準確率僅 ~0.52（期間 outcome 基率 0.617）：規則式 Agent 在這段
   被動元件盤整期的訊號偏弱且偏多，是之後接上 LLM 判讀與擴充 Agent
   的主要動機。
4. 樣本量警告：47 個事件、每檔僅 ~15 筆已結算，冷啟動（前 5 筆）又佔了
   三分之一，統計檢定力不足以下強結論；完整版（5 檔、2024 起）待額度
   允許時執行。

## 6. 後續方向

- **對數意見池（logarithmic opinion pool）**或貝氏更新取代線性池：理論上
  能在來源獨立時產生更銳利且校準的合併機率
- **精度判別力**：以 precision^γ（γ > 1）放大權重差異，或直接以校準後的
  似然比加權
- **Agent 層級的重新校準**（Platt scaling / isotonic）：在合併前先修正
  各 Agent 的過度自信，讓 precision 反映純粹的資訊量而非校準誤差
- Phase 2：供應鏈 Agent（知識圖譜傳導推論）與總經 Agent 納入合併
