# 基本面選股 + 技術面每日進出場 + 權重混合

| | |
|---|---|
| 日期 | 2026-10-10 |
| 提案 | 使用者 2026-10-10：「主要以財報基本面來選股，以技術面為進出場訊號，權重以基本面混合技術面」 |
| 方法 | **每日回測**；選股每 21 個交易日一次（21 種起點中位數），進出場每日判斷；含息總報酬、扣成本 |
| 數字 | [fund_tech_daily_data.md](fund_tech_daily_data.md)（`analysis/fund_tech_daily.py` 自動產生） |

## 設計（看結果前固定）

- **選股**：財報 Agent 連續機率在大產業內取前 1/3，加緩衝（已入選者產業內百分位 > 50% 續留），產業權重 = 股票池權重。
- **每日進出場**：第 t 日的部位只用 t−1 日收盤以前的資料決定、t 日收盤成交、賺 t → t+1 的報酬。
  - 個股濾網：入選股前一日收盤高於 60 日（或 20 日）均線才持有，跌破就該部位持現金，站回就買回。
  - 大盤濾網：0050 前一日收盤低於 200 日均線時全部持現金。
- **權重混合**：入選股在產業內依 0.5 × 財報百分位 + 0.5 × 技術面 Agent 百分位分配權重（產業總權重不變）。
- 成本：每日權重變動 × 單邊 0.29625%。最大回撤以每日淨值計，比之前以 20 日為一期計算的數字深，請與同表的對照組比較。

和[上一批](technical_timing_report.md)的差別：上一批只在換倉日（每 21 日）判斷濾網；這一批每日判斷，並加入權重混合。

## 結果

21 種換倉起點中位數：

|---|---|---|---|---|
| 基準：財報產業中性 + 緩衝 | +19.6% / 0.66 / −44% | +59.7% / 2.00 / −40% | 100% | 5.0 |

## 解讀

1. **個股的每日均線進出場傷害最大**：年換手 17–30 倍（基準 5 倍），光成本就約 5–9% / 年；
   而且電子股在均線附近反覆穿越，出場後常常馬上漲回來。樣本外年化報酬從 +19.6% 掉到 +2.8%（60 日線）/ +7.0%（20 日線），
   Sharpe 0.66 → 0.19 / 0.49。2023–2026 也一樣變差（2.00 → 1.69 / 1.12）。
2. **權重混合又是行情依賴**：2023–2026 Sharpe 2.00 → 2.08，樣本外 0.66 → 0.61。這與技術面 Agent 本身
   「2023 年後有效、樣本外無效」的結果一致（[technical_timing_report.md](technical_timing_report.md)）。
3. **大盤濾網用在選股組合上**：回撤大幅降低（−44% / −40% → −23% / −23%），2023–2026 Sharpe 提高到 2.12，
   但樣本外 Sharpe 下降（0.66 → 0.52）。
4. **唯一在兩段 Sharpe 都贏過 0050 的是「0050 + 每日大盤濾網」**（0.81 vs 0.71、2.43 vs 2.40），最大回撤減半（−34% → −16%）。
   - 這是對大盤本身擇時（Faber 2007 一類的 200 日均線規則），**不是本專案的選股能力**。
   - 上一批「每 21 日判斷一次」時同一個濾網讓 0050 的 Sharpe 下降（0.72 → 0.64），每日判斷才有改善 → 結果對判斷頻率敏感。
   - 本專案到目前為止看過的設定很多，這個結果也應該在前瞻期間再確認。
5. **財報選股的組合仍輸 0050**：電子股中小型組合的波動與回撤天生比 0050（以台積電為主的分散權值股）大；
   財報選股的超額報酬（相對等權每年約 3–5%）不足以補回這段風險差距。

## 結論

- 不採用個股技術面每日進出場、不採用權重混合（只在 2023 年後有效）。
- 如果目標是「Sharpe 贏過大盤」，在這個專案目前的訊號強度下，最直接的做法不是選股，而是**0050 搭配每日 200 日均線濾網**；
  財報選股可以視為「承擔較高波動換取較高報酬」的衛星部位（樣本外年化 +19.6% vs 0050 +13.9%，但 Sharpe 較低）。
  兩者的配置比例屬於風險偏好的決定，本報告不做建議。
- 本批共 10 種組合（7 種策略 + 3 個對照）。
