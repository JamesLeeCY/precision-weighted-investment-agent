## 結論：前提都不成立，不建立影子前瞻

影子規格：第 501–1000 名用同一套 fv5 家族規則，不限制可借、借券費 2%／年、交易成本單邊另加 0.46%（I042 估計），只當統計證據。
Sharpe 為扣成本與台指期對沖後，格式 2019–2022 / 2023–2026/04。

| 影子規格 | 全期 Sharpe | 兩段 |
|---|---|---|
| fv5-sh | 1.24 | 2.03 / 0.27 |
| fv5s-sh（加借券餘額 ts_rank） | 1.36 | 2.16 / 0.36 |
| fv5v-sh（逆波動權重） | 0.57 | 1.24 / −0.29 |
| fv5x-sh（三項合併） | 0.62 | 1.29 / −0.20 |

- **逆波動權重在中小型股有害**：波動調整後每段差 −0.24%（前 500 名 +0.07%），方向相反，所以 fv5v、fv5x 無法用影子增加證據。
- **fv5s**：兩池同號（+0.053% vs +0.041%）、相關 0.26，但合併後 50% 檢定力所需段數只從 131 降到 114（少 13%，門檻 30%）。
- **fv5e**：影子中有自結盈餘的金融股平均只有 1.9 檔，只報告。
- 依點子卡停止，不登錄影子前瞻（省下每月約 1,500–2,000 次 FinMind）。
- 附帶：fv5 在中小型股 2023 年後只有 0.27（前 500 名 1.87），與 I043 的「中小型股增量在 2023 年後變弱」一致。
- 程式修正：影子樣本中有自結盈餘、但當期沒有 SUE 分數的金融股不做替換（前 500 名從未發生，主規格結果不變）。
