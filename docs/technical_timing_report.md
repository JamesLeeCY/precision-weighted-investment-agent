| | |
|---|---|
| 日期 | 2026-10-10 |
| 股票池 | 無選股偏誤股票池（`config/tickers_pit.yaml`，每年前 100 檔、含下市股） |
| 期間 | 2019-01 ~ 2026-05 預測日；**2019–2022 為規則樣本外**（見 [overfitting_controls.md](overfitting_controls.md)），2023–2026/05 與開發期重疊 |
| 方法 | 每 21 個交易日換倉、持有 20 個交易日，21 種取樣起點的中位數；含息總報酬、扣交易成本（換手量 × 單邊 0.29625%） |

## 目的

財報 Agent 的方向準確率低、Sharpe 不如 0050（[scorecard.md](scorecard.md)）。這一批測兩件事：

1. **其他訊號有沒有產業內選股能力**：產業內相對估值（改寫自 WorldQuant BRAIN 的 industry-relative valuation alpha）、
   技術面 Agent（K 線、均線、量價、支撐壓力）、動能（12-1、6-1 個月）、短期反轉（1 個月、1 週）、財報 + 估值合成。
2. **技術面進出場濾網能不能提高 Sharpe**：大盤濾網（0050 > 200 日均線才持股）、個股濾網（股價 > 60 日均線才持有）。

所有參數都是文獻或教科書的標準值，在看結果前固定。共測 8 個訊號、10 種組合 → 多重比較嚴重，**以樣本外為主要判斷依據**。

## 一、產業內選股能力

| 訊號 | 產業內 IC 2019–2022（樣本外） | 2023–2026 | 產業中性做多 − 等權，扣成本 2019–2022 | 2023–2026 | 每期換手 |
|---|---|---|---|---|---|
| 財報 Agent（基準） | **+0.017**（16/21 起點為正） | +0.046（21/21） | **+0.13%**（19/21） | +0.47%（21/21） | 0.60 |
| 產業內相對估值 | −0.001（8/21） | −0.021（1/21） | −0.43%（0/21） | −0.74%（0/21） | 0.35 |
| 財報 + 估值 | +0.004（13/21） | +0.018（20/21） | −0.33%（0/21） | −0.26%（1/21） | 0.63 |
| 技術面 Agent | −0.035（1/21） | +0.041（21/21） | −0.40%（0/21） | +0.69%（21/21） | 0.98 |
| 動能 12-1 月 | −0.014（0/21） | +0.049（21/21） | −0.18%（4/21） | +0.70%（21/21） | 0.45 |
| 動能 6-1 月 | −0.005（8/21） | +0.032（21/21） | +0.00%（11/21） | +0.35%（21/21） | 0.61 |
| 反轉 1 個月 | **+0.045**（21/21） | −0.031（0/21） | +0.03%（13/21） | −0.98%（0/21） | 1.33 |
| 反轉 1 週 | +0.028（20/21） | −0.020（6/21） | −0.08%（5/21） | −0.36%（2/21） | 1.31 |

解讀：

1. **財報 Agent 仍是唯一兩段都為正的訊號**，但樣本外弱很多（IC +0.017、扣成本超額 +0.13%）。
2. **產業內相對估值在這個股票池無效，而且是反向的**：兩段 IC 都 ≤ 0，產業中性做多「便宜股」每期輸等權 0.4–0.7%。
   2019–2026 的台股電子是成長股行情，便宜的股票通常是基本面轉弱的公司（價值陷阱）。和財報合成後把財報訊號也拖垮了。
   原式在歐洲市場有效、且依賴子產業 × 市值的細格比較；這裡只有 7 個大產業、每年 100 檔，格子太粗。
3. **技術面與動能是行情依賴的**：2023–2026（AI 多頭）IC +0.03 ~ +0.05、21/21 起點為正；但樣本外 2019–2022 轉負
   （技術面 −0.035，1/21）。單看 2023 年後會誤以為技術面有效。
4. **短期反轉剛好相反**：2019–2022 IC +0.045（21/21），2023–2026 轉負。反轉與動能在兩段之間互換，是同一件事的兩面
   （盤整市反轉、趨勢市動能）。而且反轉每期換手 1.3，扣成本後超額只剩 0 左右。
5. 結論：**沒有一個新訊號在兩段都有效**，事後挑出任一段表現好的訊號都是過度擬合。

## 二、進出場濾網

Sharpe／最大回撤／年化報酬／平均持股比例（21 起點中位數）：

| 組合 | 2019–2022（樣本外） | 2023–2026/05 |
|---|---|---|
| 0050 買進持有 | **0.72**／−29%／+16.1%／100% | **2.09**／−17%／+46.0%／100% |
| 0050 + 大盤濾網 | 0.64／−19%／+10.3%／67% | 1.95／−13%／+42.4%／92% |
| 等權持有全部 | 0.59／−39%／+17.3%／100% | 1.61／−28%／+44.0%／100% |
| 等權 + 大盤濾網 | 0.34／−23%／+7.2%／67% | 1.70／−16%／+42.1%／92% |
| 財報產業中性做多 | 0.57／−40%／+18.4%／100% | 1.80／−27%／+53.7%／100% |
| 財報產業中性 + 大盤濾網 | 0.37／**−24%**／+8.4%／67% | 1.91／**−16%**／+50.7%／92% |
| 財報產業中性 + 個股濾網 | 0.14／−26%／+2.7%／52% | 1.90／−16%／+36.1%／62% |
| 財報產業中性 + 大盤與個股濾網 | 0.33／−17%／+4.9%／43% | 1.81／−14%／+35.5%／60% |
| 財報 + 估值產業中性 | 0.46／−40%／+13.2%／100% | 1.48／−24%／+42.6%／100% |
| 財報 + 估值 + 大盤濾網 | 0.30／−24%／+6.2%／67% | 1.54／−16%／+39.8%／92% |

大盤濾網在 22% 的預測日空手。

解讀：

1. **濾網確實降低最大回撤**：財報產業中性的回撤從 −40% / −27% 降到 −24% / −16%，0050 自己也從 −29% 降到 −19%。
2. **但樣本外 Sharpe 反而變差**（0.57 → 0.37），年化報酬從 +18.4% 掉到 +8.4%：報酬的損失大於波動的降低。
   可能原因是 200 日線是落後指標，跌破時多半已在低點附近，空手期間錯過了反彈（例如 2019-01-02 起始時就處於空手；
   2020 年 3 月急跌後的快速回升）；每 21 個交易日才判斷一次也讓濾網反應更慢。逐段歸因未另外驗證。
3. 2023–2026 濾網讓 Sharpe 小幅提高（1.80 → 1.91），但仍低於 0050 的 2.09；同一個濾網套在 0050 上也是降低 Sharpe。
4. 個股濾網（> 60 日線）大幅降低持股比例，樣本外 Sharpe 只剩 0.14。
5. **沒有任何組合在任一段的 Sharpe 贏過 0050 買進持有。** 0050 是分散的大型權值股（台積電權重高），
   電子股中小型組合的波動天生比較大；要在 Sharpe 上贏 0050，需要的是更強的選股訊號，而不是擇時。

## 三、結論與下一步

- **不採用**：產業內相對估值、財報 + 估值合成、技術面 Agent、動能、1 個月 / 1 週反轉作為選股訊號；大盤與個股濾網作為提高 Sharpe 的手段。
  技術面 Agent 已實作並接入回測（`--agents technical_agent`），保留作為研究工具，不加入預設合併。
- **可以保留的用途**：如果目標是控制回撤（例如最大回撤上限），大盤濾網能把回撤降低約 40%，代價是報酬與樣本外 Sharpe 下降。
- **下一批（使用者 2026-10-10 提出）**：5 日預測期的短期反轉（1 / 5 / 10 日報酬、減產業平均版本）、
  過度反應（反轉 × 低量，爆量為對照）、產業內領先落後（領先股過去 5 日報酬 − 自身報酬）。
  本批的 1 週反轉樣本外 IC +0.028（20 日預測期），值得在 5 日預測期上檢驗；但換手與 0.3% 證交稅會是主要障礙。

## 注意事項

- 本批共 8 個訊號、10 種濾網組合，看過的設定數多；任一單項結果都應打折看待。
- 估值版本的差異：沒有子產業分類（只有 7 個大產業）；市值由收盤價 × 普通股股本 ÷ 10 自行計算（免費層無市值資料）；
  殖利率、本益比為 TWSE / TPEx 每日公布值，使用前一交易日的數值。
- 技術指標使用含息還原的開高低收；成交量未調整分割。2019 年初前 60 個交易日指標不足（覆蓋率較低），12-1 月動能 2019 年缺值。
- 濾網只在換倉日判斷（每 21 個交易日），持有期間不中途出場。
