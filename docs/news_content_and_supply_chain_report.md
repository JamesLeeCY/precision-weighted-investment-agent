## 1. 新聞內文

### 做法

[data/fetch_article.py](../data/fetch_article.py)：

- 為新聞 Agent **檢索之後**的入選新聞補上內文摘要（og:description + 主要段落，截斷 600 字）。挑選哪些新聞的過程與只有標題時完全相同，可單獨衡量內文的效果。
- 遵守 robots.txt，同一網域請求間隔 ≥ 1 秒。
- 內文快取 `article_cache/` **只存在本機、不納入版控**：新聞內文受著作權保護，不可隨公開 repo 散布。重現實驗需自行重新抓取（`--news-content`）。

### 覆蓋率

| 狀態 | 篇數 | 說明 |
|---|---|---|
| 成功取得內文 | 371（36%） | CMoney 160、富聯網（時報資訊）73、CMoney 投資網誌 29、工商時報 12、其他 |
| Google News 轉址 | 626（61%） | 原始網址只能經由 Google 未公開的內部 API 解碼，且格式已變動，不處理 |
| HTTP 錯誤 | 30 | 404 / 403 / 429 / 504 |
| robots.txt 禁止 | 3 | |

無法解析的 Google News 連結來源很分散（富聯網 104、經濟日報 98、CMoney 90、科技新報 67、聯合新聞網 51、鉅亨 44 等），經濟日報、科技新報、聯合新聞網、鉅亨等主流媒體的內文因此幾乎都拿不到。**實際取得的內文有 43% 來自 CMoney（160/371），其中不少是自動產生的盤後文章或論壇貼文**，來源品質偏低。

### 結果

| | 只有標題 | 加上內文 |
|---|---|---|
| 新聞 Agent Brier | **0.2531** | 0.2640 |
| 有方向的判斷數 | 38 | 49 |
| 方向命中率 | **47.4%** | 38.8% |
| 橫斷面 IC（t） | +0.024（0.24） | +0.136（1.21） |
| 3 Agent 簡單平均 Brier | **0.2530** | 0.2560 |
| 3 Agent 簡單平均累積報酬 | −23.2% | −21.4% |

**內文讓規則式新聞 Agent 變差**（Brier 0.2531 → 0.2640）。原因是內文觸發的關鍵字以「法人買超/賣超」（170 次）和「漲價」（75 次）為主，多半來自 CMoney 自動產生的盤後文章中的固定段落，不是真正的事件。關鍵字比對適合短標題，用在長內文上會被雜訊帶偏。

橫斷面 IC 轉正（+0.136），但不顯著，且與 Brier、命中率的惡化方向相反，不能據此判定內文有幫助。

**結論**：在規則式判讀下，內文沒有幫助。它的價值可能要靠 LLM 判讀才能發揮，但目前可取得的內文偏向低品質來源，這點也限制了上限。

### LLM 判讀有內文的新聞（2026-10-08 補充）

用 qwen3:8b 判讀同樣有內文的新聞，3 個 Agent 都用 LLM，與 [LLM 判讀實驗](llm_experiment_report.md)（只有標題）對照。輸出：[reports/finmind_llm_qwen3_content/](../reports/finmind_llm_qwen3_content/comparison_report.md)。

**執行條件**：Ollama `num_thread: 2`，與其他工作共用電腦。開跑前先確認 CPU 沒有其他主要占用（17:21 整體 8.7%），39 次新呼叫（另有 1 次試跑、347 次快取）耗時約 3 小時 6 分（每次平均約 4.8 分鐘），0 次失敗。執行期間整體 CPU 約 25%，扣除基線後推論約占 16–17%，與 2/12 個邏輯核心一致。

| 新聞 Agent | Brier | 有方向的判斷（多/空） | 命中率 | 信心 ≥ 0.8 的命中率 | 校準後 a |
|---|---|---|---|---|---|
| 規則式・只有標題 | **0.2531** | 38（27/11） | 47.4% | — | 0.64 |
| 規則式・加內文 | 0.2640 | 49（32/17） | 38.8% | — | 0.26 |
| LLM・只有標題 | 0.2718 | 68（61/7） | 55.9% | 53%（32 筆） | 0.18 |
| LLM・加內文 | 0.2877 | 68（62/6） | 50.0% | 50%（38 筆） | **0.04** |

40 個帶內文的新 prompt 中，只有 20 個事件的 LLM 輸出改變。在這 20 個事件上：

| | 只有標題 | 加內文 |
|---|---|---|
| Brier | 0.2475 | 0.3550 |
| 命中率（18 筆有方向） | 66.7% | 44.4% |
| 平均偏離 0.5 的幅度 | 0.21 | 0.28 |

**內文讓 LLM 判讀也變差**：模型看到內文後信心更高，命中率卻下降；校準後係數只剩 0.04，代表新聞 Agent 被判定幾乎沒有判讀能力。樣本只有 20 個事件，不足以下強結論，但方向與規則式一致。

可能原因：取得的內文有 43% 來自 CMoney 的自動盤後文章與論壇貼文，充滿技術面、籌碼面的描述，讓模型對短期方向過度自信；真正有資訊量的主流媒體內文（經濟日報、科技新報等）大多因 Google News 轉址而拿不到。

合併後：3 Agent 校準後精度加權 Brier 0.2558（只有標題時 0.2544），組合報酬 −24%，仍顯著輸 0050。

## 2. 供應鏈 Agent

### 做法

[agents/supply_chain_agent.py](../agents/supply_chain_agent.py)，知識圖譜 [config/supply_chain_graph.json](../config/supply_chain_graph.json)，資料層 [data/fetch_supply_chain.py](../data/fetch_supply_chain.py)。

**依據**：經濟關聯公司之間的報酬可預測性——市場對上下游消息的反應有遲滯，下游客戶的股價動能會領先供應商（Cohen & Frazzini 2008）；產業龍頭的動能也領先同業。

| 特徵 | 計算 | 強訊號門檻 |
|---|---|---|
| 下游動能 | 下游需求代理公司 20 日超額報酬（相對加權指數），依邊權重加權 | 10% |
| 下游營收 | 下游需求代理公司最新月營收年增率（公告遞延 40 天），依邊權重加權 | 30% |
| 龍頭動能 | 國巨（龍頭 / 同集團）20 日超額報酬；國巨自身無此項 | 10% |

**知識圖譜的限制**（重要）：被動元件廠的實際客戶名單與營收占比未公開。下游節點（廣達、緯創、緯穎、鴻海、台積電）是**下游終端市場的代表性公司，作為需求代理，不是已確認的直接客戶**。邊權重（1.0 主要 / 0.5 次要）與各公司間的差異是人工假設，未經回測最佳化，需要以產業研究修訂。

look-ahead 防護：股價只用 as_of_date 前一日以前的收盤價，且使用含息還原價（國巨 2025-08 一拆四，未還原價會出現 −75% 的假跌）。

### 結果

| Agent | Brier | 有方向的判斷（多/空） | 方向命中率 | 橫斷面 IC（t） | 期末收縮係數 a |
|---|---|---|---|---|---|
| 財報 | 0.2593 | 49 / 11 | 50.0% | −0.149（−1.32） | 0.41 |
| 新聞 | 0.2531 | 27 / 11 | 47.4% | +0.024（0.24） | 0.64 |
| 總經/籌碼 | 0.2547 | 17 / 11 | 46.4% | +0.010（0.08） | 0.78 |
| **供應鏈** | **0.2652** | **69 / 4** | 58.9% | **+0.160（1.71）** | 0.22 |

| 策略 | 3 Agent（對照） | 4 Agent |
|---|---|---|
| 簡單平均 Brier | 0.2530 | 0.2529 |
| 精度加權 Brier | 0.2532 | 0.2535 |
| 簡單平均累積報酬（持股期） | −23.2%（52%） | +59.3%（56%） |
| 精度加權累積報酬 | −18.6% | +49.3% |
| 校準後策略累積報酬（持股期） | −12.3%（30%） | −3.1%（15%） |
| 0050 | +191.7% | +191.7% |

**解讀：**

1. **供應鏈 Agent 的機率品質最差**（Brier 0.2652），因為偏多且信心偏高。下游代理公司的月營收年增率全期平均約 +38%（AI 伺服器熱潮），這個分量幾乎一直是滿分看多。58.9% 的命中率主要來自「大多看多」加上 54.8% 的基率。校準把它收縮到 a = 0.22。
2. **但它是全專案第一個橫斷面 IC 為正且接近顯著的訊號**（+0.160，t = 1.71，常態近似 p ≈ 0.09）。同一時點 5 檔之間，它排得較高的股票後續報酬傾向較高，差異主要來自各公司圖譜權重與龍頭關係的不同。不過本專案至今已比較多個 Agent 與變體，考慮多重比較，這只是值得後續驗證的線索，不是結論。
3. **合併的機率品質沒有變化**（0.2530 → 0.2529）；精度比仍只有 1.05–1.24，精度加權依然略輸簡單平均。
4. **組合報酬從 −23% 變成 +59%，但不是判讀能力**：供應鏈 Agent 偏多，提高了看多訊號的比例；在 0050 年化 +61% 的多頭裡，多持股就多賺。合併策略的橫斷面 IC 仍 ≤ 0，所有策略仍輸 0050。

## 3. 結論

1. 新聞內文在規則式判讀下有害，原因是關鍵字比對被長文雜訊帶偏，加上可取得的內文偏向低品質來源。
2. 供應鏈 Agent 機率品質最差，卻帶來全專案最強的選股排序訊號（不顯著），兩者並不矛盾：Brier 衡量絕對的多空機率，IC 衡量相對排序。
3. 所有設定的 Brier 仍高於 0.25，系統整體依然沒有預測力。
