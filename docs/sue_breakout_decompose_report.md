# 拆解「月營收驚奇 + 兩日連漲進場」的超額來源（2026-10-13）

接續 [連漲進場、連跌出場](sue_breakout_report.md)：同一進場規則、只在月營收驚奇掉出產業內前 1/3 時賣出的版本，
Sharpe 1.06 / 1.56，高於月換倉的 0.91 / 1.42（2019–2022 / 2023–2026/04）。這裡拆解這段差異的來源。
完整自動產生的表格見 [sue_breakout_decompose_top300.md](sue_breakout_decompose_top300.md)。研究結果，非投資建議。

## 設計（看結果前固定）

三個因素各開或關，共 8 個版本，其他規則都相同（每次加碼 5% 基本單位、限制在 1%–10%、單檔 ≤ 20%、總持股 ≤ 100%、只在基本面不符時賣出、扣成本）：

| 因素 | 開 | 關 |
|---|---|---|
| 時點 | 兩日連漲才加碼 | 可買期間每隔 2 日就加碼 |
| 成交金額加權 | 加碼金額 × 成交金額比（0.5–2 倍） | 不乘 |
| 漲幅加權 | 加碼金額 × 兩日漲幅比（0.25–2.5 倍） | 不乘 |

## 結論

1. **分批進場、持有到基本面不符這套機制本身幾乎沒有貢獻**：「每隔 2 日、無加權」與月換倉的差只有 +1.5%／年（t 0.8）。
2. **兩日連漲的時點與成交金額加權都不穩定**：兩段的效果方向相反，主效果都在 ±0.07 以內。
   成交金額加權只是把持股推向較大的股票（市值百分位 0.53 → 0.61），在 2023 年後大型股行情中較好。
3. **唯一兩段一致的來源是「漲幅加權」**，也就是兩日漲幅愈大、加碼愈多，類似短期動能：
   - 報酬每年多約 5–9%，扣掉 0050 β 後 t ≈ 2.0；
   - 但波動也多 15–22%，所以 Sharpe 只多約 0.09。

   換句話說，它主要是加了一個風險較高的傾斜，風險調整後的改善很小。
4. **多重比較**：8 個版本加上先前的規則與對照，t ≈ 2 屬邊際，需要前瞻資料確認。
   此外，台股的 1 日短期反轉在先前研究中為正（[short_term_reversal_report.md](short_term_reversal_report.md)），與這裡的「漲多買多」方向相反，兩者的持有期不同（1–5 日 vs 數週）。
5. 2023–2026/04 所有版本仍低於 0050（1.90）；2019–2022 都高於 0050（0.80）。

## 可能的下一步（待使用者決定）

- 若要採用，最簡潔的版本是「月營收驚奇前 1/3 + 依兩日漲幅加碼」，不需要兩日連漲的時點與成交金額加權。可比照 fv2 另立前瞻規格，每月記錄。
- 直接檢驗「漲幅加權」是否只是動能：在月營收驚奇名單內，以過去 1–3 個月報酬加權，比較兩者。
