## 2. 機率品質

| 策略 | Brier ↓ | ECE ↓ | 方向準確率 |
|---|---|---|---|
| 單一 Agent（財報） | 0.2593 | 0.1174 | 0.478 |
| 簡單平均（2 Agent，對照） | 0.2556 | 0.0610 | 0.488 |
| 精度加權（2 Agent，對照） | 0.2557 | 0.0672 | 0.488 |
| **簡單平均（3 Agent）** | **0.2538** | **0.0538** | 0.494 |
| **精度加權（3 Agent）** | 0.2540 | 0.0593 | 0.494 |

個別 Agent（消融）：

| Agent | Brier | ECE | p ≠ 0.5 比例 | 橫斷面 IC（t） |
|---|---|---|---|---|
| 財報 | 0.2593 | 0.117 | 44% | −0.149（−1.32） |
| 新聞 | 0.2531 | 0.088 | 28% | +0.024（0.24） |
| 總經/籌碼 | 0.2547 | 0.095 | 21% | +0.010（0.08） |

- 加入第三個 Agent 後，合併 Brier 下降約 0.002，ECE 從 0.061 降到 0.054。分散效果隨來源增加而增強。
- **所有策略與所有個別 Agent 的 Brier 都高於 0.25**，也就是比「永遠猜 50%」還差。若改用期間基率（54.8%）當常數預測，Brier 約 0.248，差距更大。機率預測本身沒有帶來資訊，改善只是讓合併後的機率更靠近 0.5、校準更好（ECE 下降）。
- 總經/籌碼 Agent 單獨的 Brier 介於新聞與財報 Agent 之間，橫斷面 IC 約為 0。

## 3. 精度加權仍等於簡單平均

回測結束時，同一檔股票三個 Agent 的精度最大與最小比值只有 1.01–1.24。精度加權和簡單平均的合併機率平均只差 0.0014，最大差 0.0153，訊號在 135 個事件中**完全相同**。

新 Agent 沒有讓可靠度分化。三個規則式 Agent 的可靠度依然一樣接近，與 Phase 1 的結論相同。

## 4. 報酬層級

| 策略 | 累積報酬 | 年化 | Sharpe | 最大回撤 | 每期超額 vs 0050 t |
|---|---|---|---|---|---|
| 合併（2 Agent，對照） | +86.5% | +31.9% | 0.86 | −19.1% | −1.03 |
| **合併（3 Agent）** | **+182.2%** | +58.6% | 1.40 | −20.6% | +0.16 |
| 等權持有 5 檔 | +121.3% | +42.3% | 1.07 | −25.6% | −0.47 |
| 0050 | +191.7% | +60.9% | 2.48 | −15.8% | — |

**這個改善不可信，不能當成總經 Agent 有效的證據：**

1. **集中在少數期數**：27 期中只有 2 期貢獻了一大半的差距（以對數報酬計，總差距 0.41，扣掉這 2 期後剩 0.16）。最大的一期是 2026-03-11，多持有了禾伸堂，該期報酬 +82%。
2. **那一次「看多」是沒把握的判斷**：總經 Agent 對禾伸堂的訊號是 bullish，但分量互相矛盾，原始信心只有 0.45（修正後為 0.5，見第 5 節）。只因合併後分數剛好越過看多門檻才持有。
3. **排序能力沒有改善**：合併的 pooled IC 從 −0.07 變成 −0.12，橫斷面 IC 仍為負（約 −0.15，不顯著）。
4. 相對 0050 的超額報酬 t = 0.16，與 0 無差異。

結論是組合報酬的提升主要來自少數幾次運氣，不能據此宣稱總經 Agent 有選股或擇時能力。

## 5. 修正：有方向訊號的信心下限 0.5

規格 6.1 把 bullish 換算成 p = confidence。但規則式評分在訊號內部矛盾時會扣信心，曾出現「方向是 bullish、信心 < 0.5」的訊號，這時 p < 0.5，方向和機率互相矛盾：Brier/ECE 把它們當成反方向計分，合併時卻照原方向計入。

| Agent | 有方向的訊號 | 其中信心 < 0.5 | 這些訊號的方向命中率 |
|---|---|---|---|
| 財報 | 69 | 9（13%） | 33% |
| 總經/籌碼 | 43 | **15（35%）** | 33% |

使用者決策（2026-10-06）：有方向的訊號信心下限設為 0.5（`agents/base.py:_build_output`，所有 Agent 含 LLM 路徑皆適用；原始值保留於 `raw_features.confidence_raw`）。0.5 代表「有方向但無把握」，在 Brier 上等同 neutral。

- 這些訊號的方向命中率只有 33%。舊換算把它們當成反方向計分，等於歪打正著，所以修正後 Brier 略升（例如財報 Agent 0.2584 → 0.2593）。修正後的計分才是誠實的。
- 訊號方向沒有改變，組合報酬完全相同。
- 本報告與[完整版報告](finmind_full_report.md)的數字皆為修正後結果。
