## 動機

到目前為止只有 FinMind 的 7 個大產業（半導體業、電子零組件業……），產業內比較很粗：IC 設計和晶圓代工、
PCB 和被動元件被放在同一組。估值訊號原式是在「子產業 × 市值五分位」裡比較，產業領先落後也需要業務相近的同業。

## 分類方法（看回測結果前固定）

- 公司頁列出公司申報的所有「產業鏈 > 細項」（台積電：半導體 > 晶圓製造；台達電申報了 60 多筆）；
  產業鏈介紹頁把細項歸到中層分類（例如電源管理 IC、記憶體 IC → IC設計）。子產業 = 「產業鏈 / 中層分類」。
- 申報順序不代表重要性（台達電第一筆是「休閒娛樂 > 休閒車業」），主要子產業的選法：
  1. 只看電子核心產業鏈（半導體、電腦及週邊、通信網路、印刷電路板、被動元件、連接器、平面顯示器、觸控面板、LED、太陽能、能源元件）；
  2. 優先選與 FinMind 大產業對應的產業鏈；
  3. 候選產業鏈中選公司申報筆數最多者（代表主要業務），再取該鏈的第一筆。
- 抽查：台積電 → 半導體/IC/晶圓製造、聯發科 → 半導體/IC設計、日月光投控 → 半導體/IC封裝測試、台達電 → 電腦及週邊設備/電源供應器、
  欣興 → 印刷電路板/硬板軟板IC載板、國巨 → 被動元件/電阻器、智邦 → 通信網路/網路設備。
- 分組：子產業當日有 ≥ 5 檔成員才單獨成組，不足的併回大產業。平均每日 11.8 組（大產業 7 組），44% 的股票落在獨立成組的子產業。
- 限制：分類是公司**現在**的申報內容，套用到 2019 年起有輕微前視；已下市的 6 檔查不到，併回大產業。

## 結果

| 財報 Agent | 大產業 | +0.017（16/21） | +0.046（21/21） | +0.13%（19/21） | +0.47%（21/21） | 0.60 |
| 財報 Agent | 子產業 | +0.015（16/21） | +0.038（21/21） | +0.19%（21/21） | +0.36%（21/21） | 0.61 |

## 解讀

1. **財報 Agent 沒有因為子產業而變好**：組內 IC 兩段都略降（+0.017 → +0.015、+0.046 → +0.038）。
   沒有緩衝時樣本外超額從 +0.13% 升到 +0.19%，但 2023–2026 從 +0.47% 降到 +0.36%；加緩衝後兩者幾乎相同。
   財報訊號（營收成長、毛利率趨勢）的跨子產業差異本身就有資訊，切太細反而丟掉一部分。
2. **估值訊號在子產業 × 市值的格子裡有改善，但仍不能用**：樣本外 IC 從 −0.001 變成 +0.014（20/21 起點為正），
   符合原式「要在細格子裡比較」的說法；但 2023–2026 仍為負，而且組合在兩段扣成本後都虧損。
3. **領先落後在子產業內更弱**：可能是每組太小（股票池每年只有 100 檔，獨立成組的子產業平均約 5–10 檔），
   領先股（組內市值前 1/3）只有 2–3 檔，訊號很雜。
4. **主要限制是股票池太小**：100 檔分到 63 種子產業，只有 44% 的股票所在子產業有 5 檔以上。
   子產業分類要發揮作用，需要更大的股票池（例如全部上市櫃電子股約 900 檔），但小型股流動性差、成本更高。

## 結論

- 子產業分類已建立並保留（`config/subindustry_pit.csv`），可供之後的分析使用；**不改變財報 Agent 的分組**（大產業較好或相同）。
- 產業內相對估值、領先落後在子產業下仍不採用。
- 本批共 6 個 20 日組合、2 個領先落後設定。
