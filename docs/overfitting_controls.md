# 樣本外還剩多少、怎麼控制過度擬合

數字來源：[oos_report.md](oos_report.md)（`analysis/oos_report.py` 產生）、[scorecard.md](scorecard.md)、
[forward/REPORT.md](../forward/REPORT.md)。所有數字皆為含息總報酬、扣交易成本，21 種取樣起點的中位數。

## 一、資料在什麼時候被看過（樣本切分的依據）

| 時間 | 做了什麼 | 用到的資料 |
|---|---|---|
| 2026-07-03 | MVP：財報 Agent 的 5 個特徵、縮放係數（營收 YoY ÷30、動能 ÷10、毛利率斜率 ÷2、存貨 / 應收天數 ÷30）、公告遞延（月營收 40 天、季報 75 天） | 5 檔被動元件，2023-01 ~ 2026-05 |
| 2026-10-06 ~ 09 | 41 檔擴大股票池、連續輸出、無偏誤股票池（271 檔） | 2019-01 ~ 2026-05 全期 |
| 2026-10-09 | 前瞻規格 fv1 凍結（程式碼指紋） | — |
| 2026-10-09 ~ | 回填 2026-06 ~ 09（凍結後才產生） | 凍結後的新資料 |

上面這些特徵與係數從 MVP 起就沒改過（可用 `git log -- agents/fundamentals_agent.py` 驗證）。因此：

- **規則樣本外**：無偏誤股票池的 **2019–2022**。規則在時間上沒看過這段資料，271 檔裡也有 266 檔不在 MVP 的 5 檔中。
  但「改成連續輸出」「只放財報 Agent」「產業中性」這三個決定，是看過 2019–2026 全期結果之後才做的；
  只有 **MVP 原規則（門檻模式，看多就持有）** 在這段是乾淨的樣本外。
- **真正的樣本外**：前瞻驗證（2026-06 起，目前 4 期）。

## 二、樣本外還剩多少

| | 2019–2022（規則樣本外） | 2023–2026/05（與開發期重疊） |
|---|---|---|
| MVP 原規則：Sharpe／相對等權 IR | 0.48／**+0.13**（14/21 起點為正） | 1.87／+0.76（21/21） |
| 連續輸出、看多就持有（事後決定） | 0.59／+0.40（20/21） | 1.88／+0.98（21/21） |
| 產業中性做多（事後決定） | 0.57／+0.26（19/21） | 1.80／+0.80（21/21） |
| 等權持有全部（基準） | 0.59／— | 1.61／— |
| 0050 | **0.73**／— | **2.09**／— |

- **絕對 Sharpe 主要是行情**：樣本內 1.8–1.9、樣本外 0.5–0.6，但等權持有也從 1.61 掉到 0.59、0050 從 2.09 掉到 0.73。
  兩段都**沒有贏過 0050 的 Sharpe**。
- **衡量選股能力應該看相對等權的 IR**：乾淨的樣本外（MVP 原規則）只剩樣本內的約 1/6（+0.13 vs +0.76）；
  事後決定的版本保留約 1/3 ~ 1/2，但這些決定本身用到了 2019–2022 的結果。
- **Deflated Sharpe**（產業中性做多的超額報酬）：2019–2022 在嘗試 5 / 20 / 50 種設定的假設下為 0.25 / 0.08 / 0.04，
  全期（N = 20）0.24，遠低於 0.95 的顯著門檻 → **扣掉多重嘗試後沒有統計上的證據**。
- **前瞻 4 期**（凍結後回填，未扣成本）：產業內 IC 平均 +0.005；產業中性做多相對等權平均 +0.54%（3 正 1 負，最大的一期 +3.89%），
  看多就持有 −0.06%（逐期見 oos_report.md）。期數太少，不能下結論；正式檢定在 73 個 live 期數（約 6 年）。

關於「median in-sample Sharpe 1.63」：repo 中沒有這個 Sharpe 數字。最接近的是 2023–2026 段 21 起點中位數：
等權持有 1.61、財報策略 1.80–1.88；全期單一起點的財報 Agent 是 1.24。引用時請用上表的分段數字。

## 三、控制過度擬合的做法

1. **walk-forward、無前視**：每個預測日只用當時已公告的資料（月營收遞延 40 天、季報 75 天、總經籌碼只用前一日以前），
   20 個交易日到期後才更新精度與校準；共用市場日曆，避免停牌造成的取樣漂移。
2. **規則不做參數最佳化**：特徵與縮放係數是 MVP 依常識訂定（例如營收 YoY 30% 算強），之後沒有用回測調整；
   沒有做 grid search。
3. **無選股偏誤股票池**：每年只用當時的成交值前 100 檔、包含之後下市的公司；等權持有 +538% 與 0050 +566% 相當，
   確認股票池沒有事後挑選的贏家（之前手選的 41 檔等權持有 +1,493%）。
4. **以相對指標為主**：主要指標是產業內 IC 與相對等權的超額報酬，不是絕對報酬，避免把行情或產業押注當成能力。
5. **21 種取樣起點**：每 21 個交易日換倉的結果會隨起點不同而變，所有結論都檢查 21 種起點（例如 21/21 為正）。
6. **子期間一致性**：每個結論都分 2019–2023 / 2024–2026（或 2019–2022 / 2023–2026）兩段檢查。
7. **記錄嘗試次數並報告 Deflated Sharpe**：產業中性組合報告列出看過的 5 種設定；事後加的緩衝規則明確標示為事後調整。
8. **負結果照實報告**：精度加權、LLM 判讀、新聞內文、供應鏈 Agent 都沒有效果，報告保留原始數字。
9. **前瞻驗證（最重要）**：規則與評估方式在看到新資料前凍結（`forward/spec_fv1.yaml`，程式碼 SHA-256 指紋，
   改了就拒絕預測）；紀錄只能新增，每次預測後 commit / push，GitHub 時間戳證明預測在結果之前；
   事先登錄 24 期警訊、73 期正式檢定（t > 2）的標準。

## 四、面試時的回答（建議版本）

> 「規則是 2026 年 7 月用 5 檔股票、2023 年以後的資料訂的，之後沒有再調參。所以無偏誤股票池的 2019–2022
> 對規則是樣本外。那段的絕對 Sharpe 只有 0.5–0.6，比 0050 的 0.73 低；樣本內 1.8 的 Sharpe 大部分是 2023 年後的多頭。
> 看選股能力，相對等權的 IR 從樣本內 0.76 掉到樣本外 0.13，大約只剩六分之一；扣掉嘗試次數後的 Deflated Sharpe
> 也不顯著。所以我不會說這個策略能賺錢，我會說財報訊號有小而穩定的產業內排序能力（IC 約 0.03），
> 但強度不足以在成本與多重比較後確認。為了得到乾淨的答案，我把規則凍結、做前瞻驗證，用程式碼指紋和 git 時間戳
> 保證預測在結果之前；依每期 IC 的雜訊，大約需要 6 年才能達到 t = 2。」
