# 月營收驚奇（SUE）

| | |
|---|---|
| 日期 | 2026-10-12 |
| 依據 | [台股 alpha 文獻研究](taiwan_alpha_literature.md) 第 1 名：顧廣平 2010、2016；陳柔君等 2022（管理學報） |
| 股票池 | 無選股偏誤股票池（`config/tickers_pit.yaml`） |
| 數字 | [revenue_surprise_data.md](revenue_surprise_data.md)（`analysis/revenue_surprise.py` 自動產生） |

> 研究結果，不是投資建議。

## 設計（看結果前固定）

- **公告時點**：上市櫃公司須於次月 10 日前公告上月營收（遇假日順延）。FinMind 的日期欄是營收月份的次月 1 日；
  實際收錄時間欄位（create_time）只有近期才有值，無法用於歷史。**進場日 = 當月「10 日或之後第一個交易日」的下一個交易日**，
  確保所有公司都已公告。每月一次、單一路徑（共 88 期）。
- **營收驚奇 SUE** =（本月營收 − 去年同月 − μ）÷ σ；μ、σ 為過去 24 個月「營收年差」的平均與標準差（至少 12 個月）。
- **對照**：同一份準時資料的營收年增率；現有財報 Agent；SUE 與財報 Agent 的產業內百分位平均。
- **重要發現（設計時）**：現有財報 Agent 的月營收規則是「日期 + 40 天後才使用」，FinMind 日期是營收月份的次月 1 日，
  所以 9 月營收要到 11 月 10 日才會用到——**比實際公告晚約一個月**。這是保守的防前視設計，但丟掉了最新的營收資訊。

## 一、產業內 IC

| 訊號 | 20 日 2019–2022 | 20 日 2023–2026 | 40 日 2019–2022 | 40 日 2023–2026 | 60 日 2019–2022 | 60 日 2023–2026 |
|---|---|---|---|---|---|---|
| **營收驚奇 SUE** | **+0.032（t 2.0）** | **+0.059（t 2.9）** | +0.041（t 2.2） | +0.072（t 3.6） | +0.044（t 2.4） | +0.091（t 4.7） |
| 營收年增率（準時） | +0.015（t 0.8） | +0.058（t 2.8） | −0.001 | +0.075 | −0.002 | +0.085 |
| 財報 Agent（營收晚一個月） | −0.013（t −0.6） | +0.045（t 2.5） | −0.005 | +0.081 | −0.012 | +0.085 |
| SUE + 財報 Agent | +0.009（t 0.5） | +0.069（t 3.8） | +0.024 | +0.099 | +0.022 | +0.110 |

1. **SUE 是本專案第一個在 2019–2022 與 2023–2026 兩段都顯著為正的訊號**（20 日 t 2.0 / 2.9）。
2. **兩個改變都有貢獻**：只把資料改成準時（年增率），2019–2022 從 −0.013 升到 +0.015；再改成「驚奇」的定義升到 +0.032。
3. **漂移會延續**：持有期拉長到 40、60 日，IC 跟著變大（2019–2022 +0.032 → +0.044），與文獻「持有 1–12 個月有效」一致。
4. **事先反映很強**：SUE 與公告期間報酬（上月底 → 進場前一日）的產業內 IC 為 +0.14 / +0.19（t 7–9）。
   營收資訊大部分在公告前後就反映到股價（與周子安 2016 的發現一致），但公告後仍有可交易的漂移。

## 三、組合（每日回測，與[配置研究](allocation_study_report.md)同一引擎；公告期限後換倉，產業內前 1/3 + 緩衝）

年化報酬 / Sharpe / 最大回撤（每日淨值）/ 年換手：

| 組合 | 2019–2022 | 2023–2026/05 |
|---|---|---|
| **SUE 產業中性 + 緩衝** | +21.3% / 0.73 / −41% / 5.7 | +69.3% / 2.32 / −40% / 5.9 |
| SUE + 財報 Agent + 緩衝 | +20.5% / 0.70 / −45% / 5.0 | +71.2% / 2.34 / −41% / 5.2 |
| 財報 Agent + 緩衝（同樣在公告日換倉） | +18.0% / 0.61 / −46% / 5.0 | +64.7% / 2.17 / −40% / 5.6 |
| 等權持有全部 | +16.5% / 0.60 / −44% / 0.9 | +55.1% / 1.98 / −41% / 1.1 |
| 0050 買進持有 | +14.5% / 0.75 / −34% / 0.3 | +55.6% / 2.40 / −27% / 0.0 |
| 0050 + 每日 200 日線濾網 | +11.1% / 0.80 / −16% / 5.7 | +49.6% / 2.41 / −21% / 1.5 |
| **50% SUE + 50% 0050 擇時** | +17.0% / **0.88** / −27% / 5.7 | +60.2% / **2.64** / −25% / 3.7 |

1. **SUE 比現有財報 Agent 好**：Sharpe 兩段各提高 0.12 / 0.15，年化報酬多 3–5 個百分點。
2. **單獨持有 SUE 組合，Sharpe 與 0050 打平**（0.73 vs 0.75、2.32 vs 2.40），報酬高很多（+21.3% vs +14.5%、+69.3% vs +55.6%），回撤較深。
3. **與 0050 擇時部位各半混合，兩段 Sharpe 都高於 0050 買進持有**（0.88 vs 0.75、2.64 vs 2.40），報酬也較高、回撤較淺，
   是本專案目前最好的組合（之前的 50 / 50 財報選股混合為 0.85 / 2.44）。
4. 資料檔中的「每月一期」表格因期與期之間有空檔、0050 被低估（2023–2026 Sharpe 1.72），比較請以本節每日回測為準。

## 注意事項

- **多重比較較輕**：SUE 的定義來自文獻、在看結果前固定，本批只有 4 個訊號與少數組合；但這是本專案看過許多訊號後的第 N 個嘗試，仍需前瞻確認。
- **2019–2022 對 SUE 不是「規則樣本外」**：SUE 是新訊號，兩段都是第一次看；它的價值在於兩段都顯著，而不是樣本外。
- 單一路徑（每月公告日），沒有多個取樣起點；延後進場的檢查部分替代了這個角色。
- 前瞻規格 fv1 已凍結財報 Agent（含 40 天營收遞延），不能修改；若要採用 SUE 或準時營收，應另立 fv2 並從新規格開始累積。

## 結論與建議的下一步

- 採用 SUE 作為財報選股的核心訊號候選；營收使用規則應改為「公告期限後即使用」（現行 40 天遞延晚了約一個月）。
- 建議另立前瞻規格 fv2：SUE（公告期限後進場）、產業中性前 1/3 + 緩衝，與 0050 擇時部位的混合一併記錄。
- 可再檢驗：SUE 與季報盈餘驚奇的合成（陳柔君等 2022 指出三者各自獨立）、持有 40–60 日以降低換手。
