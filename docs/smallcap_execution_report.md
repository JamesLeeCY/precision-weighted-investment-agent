# I042 中小型股（第 501–1000 名）執行面前置檢查（2026-10-22）

點子卡：[I042](../research/ideas/I042-smallcap-execution-precheck.md)（strategy-scout 產生，檢定計畫看結果前固定）。完整表格見 [smallcap_execution.md](smallcap_execution.md)；
程式 [analysis/smallcap_execution.py](../analysis/smallcap_execution.py)。本檢查只看流動性、借券與避險，不看任何訊號的報酬。研究結果，非投資建議。

## 結論：L2（滑價）與 S（借券）未過 → 中小型股卡只做統計檢定

名單用月營收驚奇（SUE）產業內前／後 1/3（平均做多約 160 檔），三份資金錯開、每 3 個換倉日換倉；門檻以資金 5,000 萬為準。

| 門檻 | 結果 | 判定 |
|---|---|---|
| L1 做多權重中，單檔交易 ≤ 前 20 日平均成交值 10% 的比例 ≥ 80% | 96%（2 億時 85%，仍過） | ✓ |
| L2 單邊額外成本（半價差 + 衝擊）中位數 ≤ 0.30% | 0.46%（前 500 名同方法 0.39%） | ✗ |
| L3 新買進遇漲停買不到 ≤ 5% 權重 | 0.1% | ✓ |
| S 放空名單通過借券條件 D 的權重 ≥ 60%（兩段） | 34% / 49%（前 500 名 75% / 81%） | ✗ |
| H 最佳中型期貨殘差波動 ≤ 台指期 0.8 倍，且口數 ≤ 日均量 10% | 臺灣中型100期貨 8.8% vs 台指期 12.5%；口數占 9.0% | ✓ |

- **容量不是問題**：資金 2 億時仍有 85% 權重的單檔交易在成交值 10% 以內，以 10% 參與率完成交易的天數中位數不到 0.1 天。
- **滑價是主要成本**：額外成本中位數 0.46%（2 億時 0.57%），是回測已扣的 0.29625% 之外再加的。
  前 500 名用同一方法估計也有 0.39%，代表日資料價差估計（Abdi–Ranaldo、Corwin–Schultz 取較大者、至少 1 個升降單位）偏保守，0.30% 的門檻對這個估計方法偏嚴；但依事前規則仍判未過。
- **放空做不起來**：第 501–1000 名的放空名單只有 70% 權重近 60 日有借券成交，通過 2,000 萬元級別的深度與費率條件只有 34%–49%；費率 > 5% 的權重 19%。
- **避險**：臺灣中型100期貨（M1F）比台指期貼近中小型股（R² 0.74 vs 0.47，殘差波動 8.8% vs 12.5%），5,000 萬只需約 39 口、約日均量 9%。
  FinMind 的 M1F 資料只有 2023 年後有效；富櫃200期貨（G2F）量太小（口數占日均量約 40%）。
- **依事前對應**：L 不過 → I043 起的中小型股卡只做統計檢定；若統計通過，可交易版本只做報告用，參考建構為「只做多 + 臺灣中型100期貨避險」，並以 0.46% 為額外滑價假設。
