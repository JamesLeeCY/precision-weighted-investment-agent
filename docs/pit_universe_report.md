## 結論先講

1. **財報 Agent 的產業內選股能力在無偏誤股票池上重現了**：產業內 IC 2019–2026 合併為 +0.029（t 2.16，85 期中 55 期為正）；每日檢驗下 2019–2023 為 +0.019、2024–2026 為 +0.044，**21 種取樣起點全部為正**。這是本專案第一個在獨立股票池、兩個期間、所有取樣起點都成立的訊號。
2. **但幅度很小**：IC 約 0.02–0.04；只持有財報 Agent 看多的股票，扣成本後相對等權持有每期約 +0.26%（t 1.90），約年化 3%。
3. **合併策略在 41 檔上的優勢沒有重現**（+1.31% → −0.44%，扣成本）：那是選股偏誤。總經與供應鏈 Agent 沒有產業內選股能力，合併進來反而稀釋了財報 Agent。
4. **選股偏誤確實被移除**：等權持有本股票池累積 +538%，與 0050 的 +566% 相當（事後挑選的 41 檔為 +1,493%）。

## 1. 股票池建構

| 步驟 | 內容 |
|---|---|
| 候選池 | FinMind `TaiwanStockInfo` 中電子相關產業（半導體、電子零組件、電腦及週邊、通信網路、其他電子、電子工業）的上市櫃 4 碼普通股，**含已下市公司**：共 931 檔，其中 2019 年後下市 34 檔。只依產業分類，不看任何報酬 |
| 逐年選股 | 每年第一個交易日，依**前 60 個交易日**的平均成交金額取前 100 檔；期間交易日不足 40 天者不納入 |
| 產業 | 同一檔股票有多筆分類時取最細者（TWSE 近年將部分公司改歸泛稱「電子工業」） |
| 結果 | 8 年 × 100 檔 = 800 個名額、**271 檔不重複**；每年與事後挑選的 41 檔只重疊 16–23 檔 |

入選過、之後下市或被合併的公司：奇力新（2022 併入國巨）、晶電（2021 併入富采）、勝麗（2020 併入同欣電）、晶睿（2026 下市）。各年成交金額前幾名反映當時市場，例如 2019 年有大立光、2020 年有玉晶光，廣達、緯創要到 2024 年才進入前五。

產業組成（8 年合計 800 個名額）：半導體 350、電子零組件 162、電腦及週邊 103、電子工業 70、通信網路 66、其他電子 49。

## 4. 機率品質

期間基率 53.4%，永遠預測基率的 Brier 為 0.2489。財報 Agent 0.2573、合併 0.2523、校準後 0.2506，**仍沒有任何策略優於基率預測**。財報 Agent 的優勢在排序（哪檔相對較好），不在絕對的漲跌機率。

## 5. 解讀與限制

**為什麼這次比較可信：**
- 檢驗的是事先由 41 檔分析提出的具體假設（財報 Agent 連續分數的產業內 IC），不是在新資料上重新挑選最好的結果。
- 股票池由規則產生、含下市公司，約 8 成成員與 41 檔不同。
- 兩個期間、21 種取樣起點、回測與每日檢驗全部一致。

**仍然存在的限制：**
- **時間期間不是全新的**：2019–2026 與先前分析重疊；真正的檢驗需要未來資料（例如 2026-06 起的模擬交易）。
- **幅度小**：IC 0.02–0.04、扣成本後年化約 3%，容易被交易成本假設、流動性與執行細節吃掉。
- 產業分類以 FinMind 目前保存的版本為準，不是逐年歷史；14 檔 2019 年後下市的股票不在 TaiwanStockInfo 中；持有期間下市以最後收盤價計值（報酬略為高估）。
- 財報 Agent 的分數是 5 個規則分量的平均，事先設計、未經最佳化；但專案過程中看過許多結果，仍有一定的多重比較風險。

## 6. 建議

1. **合併時只放有產業內技能的 Agent，或依產業內 IC 加權**：目前的精度加權以 Brier 衡量，各 Agent 的 Brier 都接近 0.25、無法分辨誰有排序能力。
2. **以財報 Agent 為核心做產業中性組合**（產業內排序、產業內多空），直接利用它唯一的優勢。
3. **前瞻驗證**：凍結目前的規則與參數，從 2026-06 起逐月記錄預測，累積真正的樣本外結果。
