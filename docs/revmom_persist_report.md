# 營收動能延伸與持續性動能（2026-10-13）

依 2026-10-13 的文獻搜尋，測試兩類新訊號：
- **營收動能延伸**：台灣碩士論文指出營收動能與「營收創新高」持有 1–12 個月顯著（[airiti](https://www.airitilibrary.com/Article/Detail/U0002-2207202009464900)）。
- **持續性動能**：Chen、Hsieh、Lee 2023（Pacific-Basin Finance Journal 78）指出，台股動能消失是因為贏家／輸家換手頻繁，只取持續的贏家與輸家仍有中期獲利。另外參考 frog-in-the-pan（Da、Gurun、Warachka 2014）。

完整自動產生的表格見 [revmom_persist_top300.md](revmom_persist_top300.md)。研究結果，非投資建議。

## 結論

1. **營收創新高是第二個在兩段都顯著的選股訊號**：
   - 60 日 IC 達 +0.06 / +0.09，比 SUE 更強；
   - 與 SUE 分數相關只有 +0.40，兩者捕捉的是營收資訊的不同面向。SUE 衡量「相對過去波動的意外」，創新高衡量「是否突破長期高點」。
2. **合成是唯一通過判準的組合**：Sharpe 1.22 / 2.13，**8 年全為正**，這是目前所有建構中第一次做到。
3. **年增率加速、3 個月年增率**：IC 都顯著，但與 SUE 高度重疊（相關約 0.5），合成後反而稀釋。
4. **持續性與 frog-in-the-pan**：IC 都不顯著，只在 2023 年後為正。台股前 300 大仍看不到可靠的動能效應。

## 注意

- 這一批共測 5 個訊號，只有 1 個通過判準。
- 合成相對 SUE 的報酬差本身不顯著（t 1.7），改善幅度需要前瞻資料確認。
- 前瞻規格 fv3 已凍結為只用 SUE，不能修改。若要驗證合成版本，需另立新規格（fv4）。
