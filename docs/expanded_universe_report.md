## 結論先講

**股票池擴大 8 倍、期間拉長到 8 年後，三個 Agent 都沒有可靠的同產業選股能力。** 唯一方向一致的訊號，是財報 Agent 內部連續分數的產業內 IC（約 +0.02 ~ +0.03），幅度很小，而且 Agent 轉換成看多機率時幾乎抹掉了它。供應鏈 Agent 只在跨產業排序上為正——它捕捉的是 AI 族群輪動，不是選股；在產業內反而為負。

## 0. 重要限制：選股偏誤（look-ahead in universe）

這 41 檔是 **2026 年**依「半導體設備、功率元件、AI 供應鏈」挑選的，其中多數正是 2019–2026 的 AI 贏家。因此：

- **絕對報酬沒有意義**：等權持有 41 檔累積 +1,493%（0050 為 +566%），這主要是事後挑股的結果。
- **公平的比較基準是「等權持有同一股票池」**，以及橫斷面 IC。
- **跨產業的 IC 也會被污染**：與 AI 連結越深的股票越可能入選、也越可能大漲，任何偏向 AI 連結的訊號（例如以 NVIDIA 動能為下游代理的供應鏈 Agent）在跨產業排序上會被高估。**產業內 IC 受影響較小，是本報告的主要指標。**

## 4. 取樣起點穩健性（每個交易日，72,730 筆）

對 2019–2026 每個交易日計算 41 檔各 Agent 的輸出與 20 日含息報酬，依「每 21 天取一次」的 21 種起點分別算 IC 平均。表中為每日 IC 平均，括號內為 21 種起點中 IC 為正的個數。

**Agent 輸出的看多機率 p：**

| Agent | 全體 樣本外 | 全體 樣本內 | 產業內 樣本外 | 產業內 樣本內 |
|---|---|---|---|---|
| 財報 | +0.033（21/21） | +0.011（18/21） | +0.002（10/21） | +0.017（16/21） |
| 總經/籌碼 | +0.003（12/21） | −0.006（10/21） | −0.003（11/21） | −0.042（4/21） |
| 供應鏈 | +0.025（19/21） | +0.030（20/21） | **−0.031（2/21）** | **−0.037（3/21）** |

**Agent 內部、門檻化之前的連續分數：**

| Agent | 全體 樣本外 | 全體 樣本內 | 產業內 樣本外 | 產業內 樣本內 |
|---|---|---|---|---|
| 財報 | +0.054（21/21） | +0.004（11/21） | **+0.022（20/21）** | **+0.028（18/21）** |
| 總經/籌碼 | −0.006（7/21） | +0.006（12/21） | −0.015（6/21） | −0.025（4/21） |
| 供應鏈 | +0.040（21/21） | +0.031（19/21） | **−0.031（1/21）** | −0.012（9/21） |

解讀：

1. **財報 Agent 的連續分數是唯一兩期都為正的產業內訊號**（+0.022 / +0.028，絕大多數起點為正），與台股月營收動能效應的方向一致。但幅度很小（IC 約 0.02–0.03），單一起點的 t 值中位數約 0.8（最高約 2.0），尚不足以宣稱統計上成立；21 種起點彼此高度相關，不是 21 個獨立證據。**Agent 把分數轉成「訊號 + 信心」後，產業內 IC 降到 +0.002 ~ +0.017**——門檻化丟掉了大部分排序資訊。
2. **供應鏈 Agent 是產業輪動訊號，不是選股訊號**：跨產業排序穩定為正（但受選股偏誤汙染，見第 0 節），產業內穩定為負。它告訴你「AI 下游走強時 AI 族群會強」，但在同一族群裡，下游連結較深的股票反而稍弱。
3. **總經/籌碼 Agent 沒有訊號**，樣本內產業內甚至偏負。

- **校準後策略幾乎不持股**：校準把機率收縮到 0.5 附近，合併機率很少超過 0.55 的看多門檻，大多時間持現金，在多頭中大幅落後。這是規格 5.2 修訂（門檻 0.55 / 0.45）與校準疊加的結果：校準是對的（Agent 確實沒有把握），但「沒有把握就空手」在多頭股票池裡代價很高。

## 6. 結論

1. **擴大股票池提高了檢定力，但沒有找到可靠的選股訊號。** 5 檔時，單一起點的 IC 可以從 −0.15 擺盪到 +0.16；41 檔時財報 Agent 的產業內起點範圍縮小到 −0.025 ~ +0.051，但總經與供應鏈 Agent 在部分期間仍可低到 −0.13 ~ −0.14。整體而言，各 Agent 的產業內 IC 接近 0 或為負。
2. **最值得追的是財報 Agent 的連續分數**（產業內 +0.02 ~ +0.03，兩期一致），以及「門檻化丟資訊」這個設計問題。
3. **供應鏈 Agent 應定位為產業輪動 / 族群曝險工具**，而不是個股選擇。
4. 擴大股票池的選股偏誤無法在這個設計下消除；要做嚴格檢驗，需要「當時可得」的股票池（例如每年依當時的產業分類與市值選股，包含之後表現差或下市的公司）。

## 7. 下一步

1. **輸出連續分數而非門檻化訊號**：讓 Agent 的機率直接來自分數（例如以校準過的 logistic 映射），避免門檻化丟掉排序資訊。
2. **無選股偏誤的股票池**：以 FinMind 產業分類，每年依當時資料選股（含下市股票）。
3. **以產業中性方式評估與建構組合**：產業內排序、產業中性的多空組合。
