## 判定

1. 主檢定兩段 > 0、全期 t > 2：+1.07%（2.7，48）、+1.34%（3.7，39）、全期 +1.19%（4.4，87） → ✓
2. 迴歸 ESUE 係數全期 t > 2 且兩段同號：+1.72%（1.9，1398）、+1.08%（1.8，1212）、全期 +1.35%（2.3，2610） → ✓
3. 驗證樣本方向相同：+1.78%（1.6，39） → ✓
4. 多空兩段 Sharpe > 0（0.04 / 0.51）或濾網版兩段不低於 fv5（1.48 / 1.85 vs 1.45 / 1.87）→ ✓

**結論：訊號有效、可交易版本通過**
