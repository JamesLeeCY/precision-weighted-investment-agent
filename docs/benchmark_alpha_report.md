# fv5／fv5x 基準比較：因子迴歸 alpha 與 Deflated Sharpe（2026-11-08）

使用者要求的基準檢查，不是點子卡，沒有事前門檻，只報告。完整表格見 [benchmark_alpha.md](benchmark_alpha.md)；程式 [analysis/benchmark_alpha.py](../analysis/benchmark_alpha.py)。
報酬沿用回測的日淨報酬：扣單邊 0.29625% 與借券費、台指期對沖後。研究結果，非投資建議。

**結論：**
- 扣掉 7 個常見因子後，fv5 每年仍有約 +4.4% 的 alpha（t 3.0），fv5x 有 +4.8%（t 3.8）。fv5 的報酬不能完全用動能、小型股或波動等已知因子解釋。
- 但原始報酬中約四成來自因子曝險，主要是動能與偏向高波動股。
- 考慮做過的大量試驗（Deflated Sharpe）後，fv5x 在合理假設下仍顯著；fv5 則要看「有效試驗數」怎麼估，介於勉強與顯著之間。

## 1. 因子迴歸

- 因子共 7 個，都在前 500 名內建構。
  - MKT：加權指數含息報酬扣 1.5% 無風險利率。
  - 其餘 6 個是產業內前 1/3 減後 1/3 的多空組合：SMB（小減大）、HML（帳面市值比）、MOM（12-1 動能）、STR（前 20 日報酬）、LVOL（低波動減高波動）、BETA（高 β 減低 β）。
- 迴歸用日報酬，Newey-West 落後 5。alpha 是截距乘以 252。

| | 原始年化報酬 | alpha（年化） | t | R² |
|---|---|---|---|---|
| fv5 2019–2022 | +6.6% | +5.4% | 2.66 | 0.41 |
| fv5 2023–2026/04 | +8.2% | +3.8% | 1.94 | 0.38 |
| **fv5 全期** | +7.4% | **+4.4%** | **3.04** | 0.38 |
| fv5x 2019–2022 | +6.9% | +5.7% | 3.10 | 0.32 |
| fv5x 2023–2026/04 | +7.5% | +4.1% | 2.53 | 0.26 |
| **fv5x 全期** | +7.2% | **+4.8%** | **3.77** | 0.28 |

- 改用不分產業的因子，alpha 是 fv5 +3.9%（t 2.58）、fv5x +4.6%（t 3.63）。改用月報酬，是 fv5 +4.3%（t 2.79）、fv5x +4.9%（t 3.25）。結論不變。
- 被因子解釋掉的約 3 個百分點，主要來自兩項：
  - **動能**（係數 +0.21，t 11.7）：MOM 因子這段期間年化 +9.7%，約貢獻 2 個百分點。營收驚奇與股價動能本來就相關。有文獻（Novy-Marx 2015）認為動能本身大半來自盈餘動能，所以控制動能可能是「扣過頭」，+4.4% 應視為保守估計。
  - **偏向高波動股**（LVOL 係數 −0.15，t −7.2）：這段期間台股高波動股大幅勝出，LVOL 因子年化 −11.2%，約貢獻 1.6 個百分點。這是未定價的風格曝險：如果低波動股反過來勝出，fv5 會吃虧。I049 試過把它對沖掉，結果 Sharpe 下降，所以沒有採用。
- fv5x 的因子曝險比 fv5 小（R² 0.28 對 0.38），主要因為逆波動權重（V）降低了對高波動股的偏好（LVOL 係數 −0.04 對 −0.15）。因此 fv5x 的報酬中，alpha 占的比例較高。
- 2023 年後 fv5 的 alpha t 只有 1.94，fv5x 是 2.53。單看後半段，證據比前半段弱。

## 2. Deflated Sharpe Ratio

- 問題是：做了這麼多試驗，最好的那個 Sharpe 1.64 或 2.05，會不會只是運氣？
  - 方法（Bailey & López de Prado 2014）先算出「N 個真實 Sharpe 都是 0 的策略中，最幸運的那個預期有多少 Sharpe」（SR*）。
  - 再算實際 Sharpe 顯著超過 SR* 的機率（DSR），並把報酬的偏態與峰態納入。
- 樣本 1,735 個交易日（6.9 年）。fv5 的偏態 −0.09、峰態 3.9，接近常態，所以 Sharpe 估計沒有被肥尾嚴重扭曲。
- 試驗間的 Sharpe 標準差：從 docs/ 各報告表格收集到 147 個全期 Sharpe，標準差 0.52。

| 有效試驗數 N | SR*（年化） | fv5 DSR | fv5x DSR |
|---|---|---|---|
| 10 | 0.81 | 0.984 | 0.999 |
| 50 | 1.17 | 0.887 | 0.988 |
| 147（每個表格數字都當成獨立試驗） | 1.37 | 0.755 | 0.960 |
| 500 | 1.57 | 0.567 | 0.890 |

- N 怎麼估是關鍵。147 個數字大多是 fv5 的小修改（換權重、換執行方式等），彼此高度相關，有效試驗數遠小於 147。
  - fv5 是在大多數點子卡之前就定案的，它的試驗主要是早期的研究路徑（被動元件、多代理、fv1–fv5）。合理的 N 大約 10–50，對應 DSR 0.89–0.98。
  - fv5x 是看過點子卡結果後挑出的組合，N 應該算大一點。但即使用 147，DSR 仍有 0.96。
- 壓力測試：若試驗間標準差為 0.8 且 N ≥ 50，fv5 的 DSR 低於 0.35。這個情境假設研究過程極度發散，不像本專案的實際狀況，但也說明結論依賴假設。
- 對 0 的 PSR 兩者都接近 1。只看單一策略、不考慮試驗次數時，Sharpe 顯著大於 0 沒有疑問。

## 怎麼用在對外說明

- 可以說：「fv5 扣掉市場、規模、價值、動能、短期反轉、低波動與 β 七個因子後，每年仍有約 4% 的 alpha（t 3.0）；考慮研究過程中的試驗次數後（Deflated Sharpe），在有效試驗數 50 以內仍有約 89% 以上的信心。」
- 應該同時說明的限制：
  - 約四成報酬來自動能與高波動股的曝險。
  - 2023 年後的 alpha 證據較弱（t 1.9）。
  - 最終仍要靠前瞻記錄驗證，正式檢定時間約在 2028 年秋天。
