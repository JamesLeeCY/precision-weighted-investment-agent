# 產業中性組合報告：以財報 Agent 為核心

| | |
|---|---|
| 日期 | 2026-10-10 |
| 股票池 | 無選股偏誤股票池（`config/tickers_pit.yaml`，每年前 100 檔、含下市股，271 檔） |
| 期間 | 2019-01-02 ~ 2026-04-30 預測日，持有 20 個交易日，含息總報酬 |
| 訊號 | 財報 Agent 連續輸出機率 `pc_fundamentals_agent`（p = σ(ln3 · score · evidence)） |
| 程式 | [analysis/sector_neutral_portfolio.py](../analysis/sector_neutral_portfolio.py)（輸入為 `analysis/phase_robustness_agents.py` 的每日輸出） |
| 成本 | 換手量 × 單邊 0.29625%（同 `backtest/portfolio.py`）；放空的融券／借券成本未計 |

## 為什麼做

無選股偏誤股票池上，唯一穩健的訊號是財報 Agent 的**產業內**排序能力（產業內 IC +0.029，t 2.16，見
[pit_universe_report.md](pit_universe_report.md)）。之前的組合（看多機率 > 0.5 全部持有）會同時押產業，
超額報酬混入產業配置。這份報告直接把訊號做成產業中性的組合，檢驗產業內排序能力能不能轉成報酬、扣成本後還剩多少。

## 組合定義

每 21 個交易日換一次部位、持有 20 個交易日；同一取樣起點的各期不重疊。21 種取樣起點分別計算後取中位數。

- **產業中性做多**：每個產業內依訊號取前 1/3；產業權重固定為股票池的產業權重，所以產業配置和等權持有完全相同，
  超額只來自產業內選股。不足 3 檔或訊號全相同的產業整個持有（貢獻 0）。可實際執行。
- **產業內多空**：每個產業內前 1/3 做多、後 1/3 做空，產業權重同上；市場與產業皆中性。
  台股放空受限且借券成本未計，**只作為訊號強度的分析指標**，不是可直接執行的策略。
- 對照：等權持有全部股票（基準）、不分產業取前 1/3、看多機率 > 0.5 全部持有（現行回測做法）。

## 主要結果（事先設定：連續機率、前後 1/3、無緩衝）

每期（20 個交易日）平均報酬，21 個取樣起點的中位數；t 為每個起點約 85 期不重疊報酬的 t 值中位數。

| 組合 | 全期 2019–2026 | 2019–2023 | 2024–2026 |
|---|---|---|---|
| 產業中性做多 − 等權（扣成本） | **+0.26%**（21/21 為正，t 1.17） | +0.21%（21/21，t 0.92） | +0.37%（21/21，t 0.93） |
| 產業中性做多 − 等權（未扣成本） | +0.42%（21/21，t 2.01） | +0.36%（21/21，t 1.61） | +0.54%（21/21，t 1.30） |
| 產業內多空（扣成本） | **+0.55%**（21/21，t 1.40） | +0.45%（21/21，t 1.08） | +0.90%（21/21，t 1.13） |
| 產業內多空（未扣成本） | +0.93%（21/21，t 2.42） | +0.80%（21/21，t 1.92） | +1.33%（21/21，t 1.63） |
| 不分產業前 1/3 − 等權（扣成本） | +0.44%（21/21，t 1.81） | +0.54%（21/21，t 1.88） | +0.20%（17/21，t 0.45） |
| p > 0.5 全持有 − 等權（扣成本） | +0.28%（21/21，t 1.84） | +0.31%（21/21，t 1.48） | +0.22%（21/21，t 0.93） |

平均持股：產業中性做多 35.9 檔（股票池 100 檔）、多空合計 64.7 檔。每期換手（權重變動合計）：
產業中性做多 0.60、多空 1.28、等權 0.08。起點 0 累積（扣成本）：產業中性做多 +740%、等權 +538%；
產業內多空 +71.6%，最大回撤 −15.5%，每期勝率 55%。

解讀：

1. **產業內排序能力確實轉成了報酬**：未扣成本的產業中性做多 +0.42% / 期（t 2.01）、產業內多空 +0.93% / 期（t 2.42），
   兩個子期間與 21 個起點全部為正。這是單純的產業內選股，沒有產業押注。
2. **成本吃掉約四成**：每期換手 0.60，成本約 0.18% / 期，扣成本後 t 降到 1.17。訊號本身慢（月營收、季報），
   但排名在產業內的邊界附近常常進出，換手偏高。
3. **和不分產業的組合相比**：不分產業取前 1/3 全期扣成本 +0.44%，比產業中性做多高，但這部分包含產業押注，
   且 2024–2026 降到 +0.20%（17/21 起點為正）；產業中性做多兩期都在 +0.2% ~ +0.4%，**較穩定**。
4. **逐年**（21 起點平均，扣成本，產業中性做多 / 多空）：2019 −0.26% / −1.06%、2020 +0.53% / +1.47%、
   2021 +0.26% / +0.94%、2022 −0.07% / −0.19%、2023 +0.72% / +1.06%、2024 +0.31% / +0.54%、
   2025 +0.42% / +1.43%、2026（1–4 月）+0.53% / +0.57%。8 年中 6 年為正，2019 與 2022 為負。

## 降低換手：緩衝規則

已持有的股票只要產業內百分位仍高於 50% 就續抱（新進仍要進前 1/3；`--keep 0.5`）。這是降低換手的標準做法，
但是**看過上面的結果之後才加的**，屬於事後調整。

| 組合（扣成本） | 無緩衝 | 緩衝 50% |
|---|---|---|
| 產業中性做多 − 等權，全期 | +0.26%（t 1.17） | **+0.35%**（21/21，t 1.91） |
| 　2019–2023 / 2024–2026 | +0.21% / +0.37% | +0.36% / +0.32% |
| 產業內多空，全期 | +0.55%（t 1.40） | +0.67%（21/21，t 1.91） |
| 每期換手（做多 / 多空） | 0.60 / 1.28 | 0.44 / 0.94 |
| 平均持股（做多） | 35.9 檔 | 43.4 檔 |

緩衝把換手降了約四分之一，未扣成本的報酬也沒有變差（做多 +0.42% → +0.46%），兩個子期間更一致。

## 敏感度

全期、21 起點中位數（t 中位數）：

| 變化 | 產業中性做多（扣成本） | 產業中性做多（未扣成本） | 產業內多空（扣成本） | 每期換手（做多） |
|---|---|---|---|---|
| 預設：連續機率、前後 1/3 | +0.26%（1.17） | +0.42%（2.01） | +0.55%（1.40） | 0.60 |
| 前後 1/5 | +0.32%（1.08），19/21 為正 | +0.52%（1.78） | +0.71%（1.58） | 0.76 |
| 原始規則分數 score | +0.24%（1.10） | +0.40%（1.95） | +0.52%（1.33） | 0.61 |
| 門檻模式機率 p | +0.05%（0.18），12/21 為正 | +0.26%（1.02） | +0.56%（1.19） | 0.82 |

- **前後 1/5** 集中在最極端的股票：2024–2026 很強（做多扣成本 +0.79%、多空 +1.85%，t 2.03），
  但 2019–2023 做多扣成本 −0.04%（8/21 為正）→ 極端端的報酬依賴行情，1/3 較穩。
- **score 與連續機率幾乎相同**（連續機率多乘了資料覆蓋率）。
- **門檻模式明顯較差**：門檻化後大量同分，排序資訊流失、換手更高（與 [continuous_output_report.md](continuous_output_report.md) 的結論一致）。

## 注意事項

- **多重比較**：本報告共看了 5 種設定（預設、緩衝、1/5、score、門檻 p）；預設設定是事先選的，其餘是敏感度或事後調整。
  主要結論以預設設定為準。
- **t 值**：每個起點約 85 期，未扣成本的 t 約 2.0–2.4，扣成本後 1.2–1.9。訊號是小而穩定的正值，不是強訊號。
- **放空不可行性**：產業內多空只是衡量訊號強度。台股融券有限額、平盤以下放空限制、借券費用，實際放空的報酬會更低。
- **未含市場衝擊**：股票池是成交值前 100 檔，流動性好，但做多 36–43 檔、每期換手 0.44–0.60 仍有滑價。
- 前瞻驗證規格 fv1 已凍結，主要指標是產業內 IC，不受本報告影響；本報告的組合可以從前瞻紀錄另外計算，作為探索性指標。

## 結論與後續

1. 財報 Agent 的產業內排序能力能轉成產業中性的超額報酬：未扣成本 +0.4% / 期（做多）、+0.9% / 期（多空），
   兩期、21 起點全部為正；扣成本後 +0.26% / 期（加緩衝 +0.35%，t 1.91）。
2. 主要損耗在換手。訊號更新慢（月營收、季報），之後可以試：換倉頻率改為每 2 期、只在月營收公布後換倉、
   以分數變化而非排名邊界決定進出。
3. 依此結果，合併預設改為只放財報 Agent（`config/*.yaml` 的 `agents`，2026-10-10）；其他 Agent 加入合併只會稀釋這個訊號。
