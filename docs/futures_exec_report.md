# I031 用股票期貨執行 fv5（2026-10-21）

點子卡：[I031](../research/ideas/I031-fv5-single-stock-futures-execution.md)（strategy-scout 產生，檢定計畫看結果前固定）。
完整輸出見 [futures_exec.md](futures_exec.md)，程式 [analysis/futures_exec.py](../analysis/futures_exec.py)。研究結果，非投資建議。

## 做了什麼

- **標的對照**：從期交所標的清單取得目前上市中的標準型（2,000 股）股票期貨，共 249 檔。其中曾為前 500 名、且 FinMind 有資料的有 245 檔，約抓了 245 次 FinMind。
  - strategy-scout 估計的 495 個代號包含小型（100 股）期貨與 ETF 期貨；標準型其實只有 249 檔。
- **期貨連續報酬**：用一般交易時段的月契約結算價，持有近月，到期前 3 個交易日轉到次月。
- **看策略結果前的前置檢查**：把每檔每月的期貨報酬和現股含息報酬相比，差距（追蹤誤差）的絕對值中位數必須 < 0.5%。

## 結果：追蹤誤差略超過門檻，依點子卡停止（沒有看任何策略報酬）

| 期貨月報酬 − 現股含息月報酬（17,810 個股票月） | 絕對值 |
|---|---|
| 中位數 | **0.53%**（門檻 < 0.5%） |
| 第 75 百分位 | 0.99% |
| 第 95 百分位 | 3.16% |

- 依事前規定停止，不做 V1／V2 模擬，也沒有看任何 Sharpe。
- **追蹤誤差的來源，大部分是可預期的系統性差異，不完全是資料問題**：
  - **股利**：期貨價格已扣掉預期現金股利，除息月份期貨不會像現股含息報酬那樣「多拿」股利。台股殖利率高，除息月份差距常達 1–5%，這是第 95 百分位偏高的主因。
  - **持有成本**：期貨價格含資金成本（約年 1–2%，每月 0.1–0.2%），每月有固定的小差距。
  - **結算價與收盤價的時間差**，以及流動性差的契約價格跳動。
- 這些差異對多空組合的影響有正有負：做多用期貨要放棄股利，放空用期貨不必付股利。所以 0.5% 的門檻可能定得太嚴。但這是事前固定的條件，不能看結果後放寬。

## 結論與建議

- I031 依點子卡停止，不另立 fv5f，fv5 不變。
- 如果仍想評估期貨執行，需要另立點子卡並事前修改設計，例如：
  - 追蹤誤差改成和「現股價格報酬（不含息）扣持有成本」比較，或只看非除息月份；
  - 股利改在模擬中明確處理：做多期貨扣股利、放空期貨加股利。
- 這是看過這次追蹤誤差數字後才提出的修改，屬於事後設計。是否值得再做，請你決定。
- 已抓的 245 檔股票期貨資料留在快取，重做不需要再抓。
