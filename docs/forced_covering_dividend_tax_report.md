## I058 融券強制回補（I050 修訂版）：未通過（P2 不成立；高融券股的強勢多半是先前漲勢的延續）

- 事件：官方停券首日 s（最後回補日），前 500 名 7,143、第 501–1000 名 6,592、第 1001–1500 名 5,605 個。
- 前置（不看報酬）：除權息類的股利公告日早於 s − 5 個交易日只有 78%（門檻 90%），股東常會類以前一年加 52 週預測命中 58%（門檻 70%）——
  兩類的停券日期都無法可靠地事前得知（股利公告常在除息前 2 週內），依點子卡兩類都只做統計檢定、不算可交易版本。
- 結果：CAR = 產業調整累積異常報酬，[s − 4, s]；高 − 低 = 融券餘額占股本前 20% 減後 20%；括號為依 s 日群聚的 t。

| 統計量 | 2019–2022 | 2023–2026/04 | 全期 |
|---|---|---|---|
| **P1 第 501–1000 名 高 − 低** | +0.84%（2.3） | +0.98%（2.5） | +0.90%（3.4） |
| **P2 控制借券餘額比、殖利率、SUE、前 20 日報酬、市值後的 MSR 係數** | | | +0.45%（1.3） |
| **P3 第 1001–1500 名 高 − 低** | | | +0.97%（4.1） |
| **P4 前 500 名 高 − 低** | | | +0.60%（3.3） |
| 只報告：第 501–1000 名 高 − 低 先行 [s − 15, s − 5] | +1.50% | +2.20% | +1.83%（5.2） |
| 只報告：第 501–1000 名 高 − 低 反轉 [s + 1, s + 5] | −1.33% | −0.85% | −1.10%（−4.8） |
| 只報告：第 501–1000 名全部事件 CAR[s − 4, s]（產業調整） | +0.26% | +0.32% | +0.29%（5.3） |

- 高 − 低的差在三個名次組都成立，但控制借券賣出餘額比與前 20 日報酬後只剩 t 1.3；而且高融券組在回補前 10 日就已多漲 1.8%、回補後 5 日回吐 1.1%。
  比較像是「漲多的股票吸引融券、之後短期反轉」，而不是回補本身的買壓。依點子卡（P1–P4 須全成立）判為未通過。
- **I059 啟動條件成立**：第 501–1000 名全部停券事件 [s − 4, s] 產業調整後 +0.29%（t 5.3），無條件的回補前偏強確實存在（I056 的前 500 名 +0.72% 在其他名次組複製）。
  但停券日期約 22%–42% 無法在 s − 5 前確知，I059（空方新倉避開停券窗）的實際可用性需考慮這點。

## I060 現金股利發放日的再投資買壓：未通過

- FinMind TaiwanStockDividend 在 2019 年以前沒有參與分派股數（多數也沒有發放日），無法算發放金額，所以 2007–2018 段無資料，只有 2019 年後可檢定。
- 發放日公告早於發放日 ≥ 5 個交易日的比例 90%（門檻 95%）。
- b（每增加一個「該年平均發放日規模」的發放金額，對發放日與次一日加權報酬指數報酬的影響）：2019–2022 +0.032%（t 1.9）、2023–2026/04 +0.032%（t 0.9）；
  發放額前 20% 的日子減無發放日，2019–2022 為 −0.10%、2023 年後 +0.06%。方向不一致，未通過。

Sharpe 為扣成本與台指期對沖後，格式 2019–2022 / 2023–2026/04；稅負只計多方持股的股利（空方權益補償已含在含息報酬中）。

## I059 fv5 空方新倉避開停券窗：未通過（只在 2023 年後有效）

使用者依 I058 的啟動條件（第 501–1000 名無條件回補前偏強，市場調整 +0.47%、t 2.9）決定執行。完整表格見 [fv5_short_defer.md](fv5_short_defer.md)；程式 [analysis/fv5_short_defer.py](../analysis/fv5_short_defer.py)。

- 規則：換倉日新建或加碼的空單，若事前可知的停券首日落在 10 個交易日內（除權息類需已公告；股東常會類用前一年加 52 週預測、延到預測日 + 3），延到那天收盤才放空，期間用 β × 台指期暫代。
- 受影響的新空單權重 6.1%（470 筆），平均延後 6.3 個交易日；延後期間這些股票相對 β × 台指期平均 +0.52%，買壓確實被避開。

| 規格 | Sharpe（2019–2022 / 2023–2026/04） | 全期 | 年化淨報酬 |
|---|---|---|---|
| fv5（現行） | 1.45 / 1.87 | 1.64 | +7.53% |
| fv5 + 延後新空單 | 1.45 / 1.92 | 1.66 | +7.63% |
| 只報告：fv5x + 延後新空單 | 1.90 / 2.28（fv5x 1.91 / 2.22） | 2.07（2.05） | +7.42%（+7.37%） |

- 年化多 +0.11 個百分點（門檻 +0.10），但 2019–2022 為 −0.01%、只有 2023 年後 +0.22%，每次換倉配對差 t 1.6，未通過。依點子卡停止，不調整 10 日視窗或預測誤差重測。
