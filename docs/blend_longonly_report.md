# 0050 擇時 + 多空混合、月營收驚奇做多與做多降換手（2026-10-14）

回測期間 2019-03-12 ~ 2026-04-30。主要看全市場市值前 500 檔（前瞻規格 fv5 的股票池），前 300 檔作對照。
完整自動產生的表格見 [blend_longonly_top500.md](blend_longonly_top500.md)、[blend_longonly_top300.md](blend_longonly_top300.md)。
研究結果，非投資建議；不代表任何個人的配置建議。

## 設計（看結果前固定）

- **對照組**：
  - 0050 買進持有；
  - 0050 + 200 日線 ±2% 緩衝帶擇時（沿用 [allocation_study_report.md](allocation_study_report.md) 的規則與成本）；
  - 等權持有整個股票池。
- **多空**：月營收驚奇（SUE）等權多空，用 fv3 建構，即限制可借、每 3 個月換倉、三份資金錯開；扣交易成本與借券費，以台指期對沖。
- **混合方式**：
  - 資金分配：a × 擇時 0050 +（1 − a）× 多空，a = 50% / 75%；
  - 疊加：100% 擇時 0050 + k × 多空，k = 0.5 / 1.0。
- **做多**：產業內 SUE 前 1/3 等權，不對沖，分三種換倉方式：
  - 每月；
  - 每月 + 緩衝（已持有的股票只要仍在前 1/2 就續抱）；
  - 每 3 個月、三份資金錯開。
- **成本**：兩個部位之間的再平衡成本忽略。

## 結果（前 500 檔）

Sharpe = 年化報酬 ÷ 年化波動（無風險利率 0），兩段為 2019–2022 / 2023–2026/04。超額 = 相對 0050 買進持有的年化報酬差（括號 t 值）。

| 0050 + ±2% 緩衝帶擇時 | 1.06 / 1.92 | +27.7% | 17.2% | −21.3% | −1.9%（−0.4） |

| **50% 擇時 0050 + 50% 多空** | **1.38 / 2.17** | +17.6% | 9.3% | **−11.6%** | −11.2%（−2.0） |

前 300 檔的結論相同：50% 擇時 0050 + 50% 多空為 1.24 / 2.21；做多每 3 個月為 0.90 / 1.51，年化 +23.4%。

## 解讀

1. **擇時 0050 加上月營收驚奇多空，兩段 Sharpe 都明顯高於 0050**：
   - 多空與 0050 的相關只有 +0.18，加入後幾乎不增加波動，卻穩定增加報酬。
   - 資金各半時，Sharpe 1.38 / 2.17（0050 為 0.73 / 1.90），最大回撤 −11.6%（0050 為 −34%）。
   - 代價是年化報酬只有 +17.6%，低於 0050 的 +29.1%。這段期間是強多頭，0050 年化近 30%。
2. **疊加做法同時拿到大盤報酬與選股報酬**：
   - 100% 擇時 0050 + 1 倍多空，Sharpe 同樣是 1.38 / 2.17，年化 +37.0%，比 0050 多 +5.5%／年（t 1.1，不顯著），回撤 −22%。
   - 但這需要多空部位所需的額外保證金與借券額度，相當於使用槓桿，只能當作上限參考。
3. **月營收驚奇做多不對沖，仍輸 0050**：
   - 年化 +22.7% 對 0050 的 +29.1%；2023 年後 Sharpe 1.40 對 1.90。
   - 它比等權持有股票池多約 +6%／年，選股能力確實存在；但「等權持有中小型股」相對「市值加權、台積電主導」的結構差更大。這和台指期對沖時看到的結構差是同一件事（[leg_pool_report.md](leg_pool_report.md)）。
4. **做多版改每 3 個月換倉，表現幾乎不變，換手減半以上**：
   - 年換手 9.3 → 3.9 倍，Sharpe 0.96 / 1.40 → 0.94 / 1.39。
   - 若採用做多版，每 3 個月三份錯開是較省成本的做法（待辦第 5 項）。

## 注意

- **±2% 緩衝帶是事後挑的**：它是看過 7 種擇時規則後選出的（[allocation_study_report.md](allocation_study_report.md)），擇時的貢獻可能高估。改用買進持有 0050 的 50 / 50 混合為 1.01 / 2.13，仍高於 0050，但 2019–2022 的優勢較小。
- **混合比例沒有最佳化**：這裡只測了兩三個比例，不是挑過的最佳值。
- **再平衡成本沒有計入**：兩個部位之間的再平衡成本忽略，疊加做法的融資成本也沒有計入。
- **只有一段多頭**：2019–2026 只經歷一段多頭（含 2022 年空頭），結果與大盤的走勢有關。
