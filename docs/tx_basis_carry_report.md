# I080 台指期扣除預期股息後的超額逆價差（2026-10-28）

點子卡：[I080](../research/ideas/I080-tx-dividend-adjusted-basis-carry.md)（strategy-scout 產生，檢定計畫看結果前固定；本批 5 張卡 Holm 最嚴門檻 t ≥ 2.58）。
完整表格見 [tx_basis_carry.md](tx_basis_carry.md)；程式 [analysis/tx_basis_carry.py](../analysis/tx_basis_carry.py)。研究結果，非投資建議。

**結論：未通過。** 扣掉預期股息後，台指期平均只比現貨便宜 0.13%，而且這個折價只存在於 2023 年以前。

## 基差

- 基差以占加權指數的百分比表示，負值代表期貨比現貨便宜。
- 預期股息依前 1500 名上市股票的現金除息估算，期間內共 5,674 筆。

| 項目 | 2018-07 ~ 2022 | 2023 ~ 2026/04 | 全期 |
|---|---|---|---|
| 原始基差（F − S）÷ S | −0.28% | −0.01% | −0.16% |
| 調整後基差 EB（加回預期股息、扣資金成本 1.5%） | −0.24% | +0.02% | −0.13% |
| EB < 0 的日數比例 | 83% | 46% | 68% |

## 主判定：c = 多台指期、空含息現貨的日報酬

| 項目 | 2018-07 ~ 2022 | 2023 ~ 2026/04 | 全期 |
|---|---|---|---|
| c 年化 | +3.65% | −0.96% | +1.72%（Newey-West t 2.10） |

- 第一項標準未過：t 2.10 < 2.58，而且 2023 年後 c 為負。
- 第二項標準有過：前一日 EB 最便宜三分之一的 c 年化 +32.3%，最貴三分之一 −25.8%。
  - 這個價差大部分無法交易，應該是日內雜訊的均值回歸。台指期與現貨的收盤時間不同（13:45 對 13:30），收盤價又有雜訊，前一日看起來偏便宜，隔日多半就會回到原位。
  - 實際用 0050 交易的條件版本只剩 Sharpe 0.81，可以佐證這一點。
- 結果對資金成本假設很敏感（只報告）：
  - r = 0% 時 c 年化只有 +0.22%（t 0.26）。
  - r = 2.5% 時為 +2.72%（t 3.32）。
  - 判定在看結果前就固定用 r = 1.5%。

## 只報告項目

- 可交易版本（多台指期、空 0050，每個結算日用迴歸重設比率，扣 0050 借券費）：
  - 無條件持有：Sharpe 0.18 / −1.01，全期 −0.33，年化 −2.02%。
  - 只在前一日 EB < 0 時持有：Sharpe 0.61 / 1.19，全期 0.81，年化 +3.79%，最大回撤 −9.7%。這一版是事後條件，依點子卡不另立規格。
- 對 fv5 的含意：fv5 兩腿的 Σwβ 平均約 0，台指期對沖部位平均接近零。以 c 計算的對沖成本約 −0.03%／年，改放空 0050 也只省約 0.01%／年，所以不需要改對沖工具。
- 0050 長期持有比「台指期加 1.5% 現金」每年多 1.11%。2023 年後逆價差消失，用台指期取代現股做多已經沒有成本優勢。

## 處置

依點子卡規定，不改資金利率、條件或期間重測。fv5 維持台指期對沖。
