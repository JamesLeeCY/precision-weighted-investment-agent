# 配置研究：擇時規則、混合比例、個股權重

| | |
|---|---|
| 日期 | 2026-10-12 |
| 提案 | 使用者 2026-10-12：比較大盤擇時規則，以及要最大化報酬時的權重配置；依序做「2 擇時規則 → 1 混合比例 → 3 個股權重」 |
| 方法 | 每日回測、扣成本；選股部位為財報產業中性 + 緩衝（21 種換倉起點中位數），0050 擇時為單一路徑 |
| 數字 | [allocation_study_data.md](allocation_study_data.md)（`analysis/allocation_study.py` 自動產生） |

> 這是歷史回測的研究結果，不是投資建議。所有數字都是在看過許多設定之後得到的，應在前瞻期間再確認。

## 設計（看結果前固定）

- **擇時規則**（0050 含息還原價；第 t 日部位只用 t−1 日收盤以前的資料決定、t 日收盤成交；空手時現金報酬 0）：
  買進持有、120 / 200 / 250 日線、雙均線（50 日 > 200 日）、200 日線 ±2% 緩衝帶（漲破均線 2% 才買、跌破 2% 才賣）、200 日線每週判斷。
  200 日線每日判斷在上一批已看過結果。
- **混合比例**：a ×「0050 + 每日 200 日線濾網」+（1 − a）× 財報選股，a = 100 / 75 / 50 / 25 / 0%，每日固定比例（兩部位間的再平衡成本忽略）。
  事先固定用 200 日線，而不是本研究事後最好的緩衝帶；另以 0050 買進持有作對照。
- **個股權重**：選股不變，產業內權重改為等權 / 財報百分位 / 60 日波動度倒數 / 市值（產業總權重不變）。

## 一、擇時規則（0050）

年化報酬 / Sharpe / 最大回撤 / 平均持股比例：

| 規則 | 2019–2022（樣本外） | 2023–2026/05 | 每年進出次數 |
|---|---|---|---|
| 買進持有 | +15.0% / 0.77 / −34% / 100% | +56.0% / 2.41 / −27% / 100% | 0 |
| 120 日線 | +11.5% / 0.85 / −16% / 68% | +43.7% / 2.15 / −21% / 88% | 7.2 |
| 200 日線（上一批已看過） | +11.0% / 0.80 / −16% / 67% | +50.0% / 2.42 / −21% / 92% | 3.8 |
| 250 日線 | +11.1% / 0.78 / −22% / 71% | +46.2% / 2.22 / −21% / 93% | 4.4 |
| 雙均線 50 > 200 | +9.8% / 0.62 / −28% / 69% | +40.7% / 1.82 / −27% / 90% | 1.0 |
| **200 日線 ±2% 緩衝帶** | +13.7% / **0.99** / −17% / 67% | +50.0% / **2.42** / −21% / 92% | 1.0 |
| 200 日線每週判斷 | +10.1% / 0.72 / −24% / 67% | +51.1% / 2.47 / −21% / 92% | 1.8 |

1. **所有擇時規則的年化報酬都低於買進持有**（兩段都是）。擇時降低的是風險，不是提高報酬。
2. **200 日線 ±2% 緩衝帶樣本外 Sharpe 最高**（0.99 vs 買進持有 0.77），2023–2026 與買進持有相當（2.42 vs 2.41；
   每週判斷 2.47 略高，但樣本外只有 0.72），最大回撤減半；
   緩衝帶讓每年進出次數從 3.8 次降到 1 次，減少在均線附近被來回洗掉。
3. 120 日線樣本外不錯但 2023–2026 明顯落後；雙均線兩段都最差；每週判斷樣本外較差。
4. 7 種規則中挑出最好的一種本身就是多重比較；緩衝帶的 ±2% 也是常見但任意的參數，沒有測過其他寬度。

## 二、混合比例：0050 擇時部位 a + 財報選股 1 − a

| 0050 部位 | a | 2019–2022（樣本外） | 2023–2026/05 |
|---|---|---|---|
| 0050 + 200 日線濾網 | 100% | +11.1% / 0.80 / −16% | +49.6% / 2.41 / −21% |
| 0050 + 200 日線濾網 | 75% | +13.9% / **0.89** / −22% | +52.9% / **2.53** / −22% |
| 0050 + 200 日線濾網 | 50% | +16.4% / 0.85 / −30% | +55.6% / 2.44 / −25% |
| 0050 + 200 日線濾網 | 25% | +18.4% / 0.76 / −37% | +57.9% / 2.24 / −33% |
| 財報選股（0%） | 0% | **+19.9%** / 0.68 / −44% | **+59.7%** / 2.00 / −40% |
| 0050 買進持有 | 75% | +16.3% / 0.79 / −35% | +57.2% / 2.43 / −30% |
| 0050 買進持有 | 50% | +17.8% / 0.77 / −38% | +58.4% / 2.35 / −33% |
| 0050 買進持有 | 25% | +19.0% / 0.73 / −41% | +59.2% / 2.19 / −37% |
| 對照：0050 買進持有 | 100% | +14.9% / 0.77 / −34% | +55.6% / 2.40 / −27% |

1. **報酬與風險是單調的取捨**：財報選股比例越高，年化報酬越高、最大回撤越深、Sharpe 越低。**要最大化報酬就是 100% 選股部位**
   （樣本外 +19.9%、2023–2026 +59.7%），但回撤約 −40% 到 −44%。
2. **擇時部位與選股部位混合有分散效果**：75% 擇時 + 25% 選股的 Sharpe 兩段都比任一部位單獨高（0.89 / 2.53）；
   50 / 50 在兩段的 Sharpe（0.85 / 2.44）與報酬（+16.4% / +55.6%）都不低於 0050 買進持有，最大回撤較淺（−30% / −25% vs −34% / −27%）。
   原因是擇時部位在空頭轉現金，正好在選股部位回撤最深的時候降低曝險。
3. 和 0050 買進持有混合則沒有這個效果（Sharpe 隨選股比例單調下降），因為兩者在空頭時一起下跌。

## 三、個股權重方法（選股：財報產業中性 + 緩衝）

| 權重 | 2019–2022（樣本外） | 2023–2026/05 | 年換手（樣本外） |
|---|---|---|---|
| 等權 | +19.9% / 0.68 / −44% | +59.7% / 2.00 / −40% | 5.0 |
| 財報百分位加權 | +19.1% / 0.65 / −45% | +60.9% / 2.03 / −39% | 5.6 |
| 60 日波動度倒數 | +19.9% / **0.71** / −42% | +55.4% / 1.94 / −39% | 5.7 |
| 市值加權 | +18.3% / 0.69 / −44% | **+73.2% / 2.57** / −34% | 5.3 |

1. **沒有一種權重在兩段都勝出**。市值加權在 2023–2026 大幅領先（年化 +73%），因為產業內市值最大的公司（台積電等）
   正是 AI 行情的最大贏家；樣本外與等權相近（+18.3% vs +19.9%）→ 屬於行情，不是穩定的優勢。
2. 波動度倒數樣本外 Sharpe 略高（0.71 vs 0.68），但 2023–2026 較低；依財報分數加權沒有比等權好。
3. 等權仍是兩段表現最平均的選擇。

## 結論（研究層面）

- **擇時規則**：本研究中 200 日線 ±2% 緩衝帶樣本外 Sharpe 最高、2023–2026 與買進持有相當，回撤減半、進出次數最少，但年化報酬低於買進持有；
  它是 7 種規則中的事後最佳，需要前瞻確認。
- **最大化報酬**：回測中報酬最高的是 100% 財報選股部位（等權），但最大回撤約 −44%、Sharpe 最低；更集中或市值加權
  在 2023 年後的多頭更高，樣本外沒有優勢。
- **兼顧報酬與風險**：0050 擇時部位與財報選股部位混合，在兩段都比單一部位的 Sharpe 高；50 / 50 的報酬不低於 0050 買進持有、回撤較淺。
- 實際配置比例取決於可承受的回撤，屬於個人決定；本報告不做建議。
- 本研究共 7 種擇時規則、8 種混合、4 種權重。
