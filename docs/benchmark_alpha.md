## Deflated Sharpe Ratio

- 試驗間 Sharpe 標準差：從 docs/ 報告表格收集到 147 個全期 Sharpe（各點子卡與 fv5 變體），標準差 0.52、中位數 1.63。這些多半是 fv5 的小修改，彼此高度相關，所以「有效試驗數」遠小於 147；下面以 N 做敏感度分析。
- SR* = 在 N 個真實 Sharpe 都是 0 的試驗中，運氣最好的那個預期能有的年化 Sharpe；DSR = 實際 Sharpe 顯著高於 SR* 的機率（Bailey & López de Prado 2014，已考慮偏態與峰態）。

- fv5：全期年化 Sharpe 1.64，1735 個交易日（6.9 年），偏態 -0.09、峰態 3.9；PSR（對 0）1.0000。
- fv5x：全期年化 Sharpe 2.05，1735 個交易日（6.9 年），偏態 -0.12、峰態 4.1；PSR（對 0）1.0000。
