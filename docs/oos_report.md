### Deflated Sharpe（產業中性做多相對等權的超額報酬）

在嘗試過 N 種設定的前提下，觀察到的超額 Sharpe 高於「N 次嘗試中最好的純雜訊」的機率（Bailey & López de Prado 2014；21 起點中位數）：

- 2019–2022：N = 5 → 0.25；N = 20 → 0.08；N = 50 → 0.04
- 全期 2019–2026：N = 20 → 0.24

一般以 > 0.95 視為顯著。
