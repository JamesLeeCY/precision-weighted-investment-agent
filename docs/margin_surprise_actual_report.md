# I048 利潤率驚奇改用季報實際公告日（2026-10-22）

點子卡：[I048](../research/ideas/I048-margin-surprise-actual-announcement-date.md)（strategy-scout 產生，檢定計畫看結果前固定）。完整表格見 [margin_surprise_actual.md](margin_surprise_actual.md)；
程式 [analysis/fetch_fin_report_dates.py](../analysis/fetch_fin_report_dates.py)、[analysis/margin_surprise_actual.py](../analysis/margin_surprise_actual.py)。研究結果，非投資建議。

## 結論：未通過（前 500 名改用實際公告日仍不顯著；中小型股反而更強）

- **公告日資料**：公開資訊觀測站重大訊息全文檢索（主旨含「財務報」與「董事會」），2020-07 ~ 2026-05 共 56,641 則，約 1,400 次請求（不占 FinMind 額度）。
  - 前 500 名非金融股 23 季的覆蓋率都在 81%–91%（門檻 80%），全部保留。
  - 公告日距法定期限的日曆日中位數：第 1–3 季約 6–9 日、年報約 21–25 日；距期限 ≥ 5 個交易日的事件占 65%。
- **訊號 MS***：季營業利益率年變動，扣掉同產業前 8 季「營收年增率 → 利益率變動」的預測值（不用尚未公告的同業），再除以公司前 8 季的變動標準差。
- **結果**：IC 為產業內 Spearman（−1～1，0 為無預測力），每季一個截面，括號為 Newey-West t。

| 統計量 | 2020Q3–2022 | 2023–2026/04 | 全期 |
|---|---|---|---|
| **P1 前 500 名：實際公告日到法定期限這段** | −0.026（−1.1） | +0.051（2.3） | +0.019（1.0） |
| **P2 前 500 名：實際公告日起 60 日** | −0.003 | +0.031 | +0.016（0.9） |
| 只報告：前 500 名期限版 60 日 | +0.008 | +0.008 | +0.008（0.3） |
| **控制 SUE、營收年增率、市值等後（60 日報酬差）** | +2.84% | +1.46% | +2.05%（t 1.2） |
| **確認：第 1001–1500 名 P1** | +0.039 | +0.107 | +0.079（3.2） |
| 只報告：第 501–1000 名 P1 ／ P2 | | | +0.064（3.6）／ +0.063（5.6） |
| 只報告：第 1001–1500 名 P2 | | | +0.042（4.6） |

- 前 500 名：實際公告日版本比期限版略好（60 日 IC +0.016 vs +0.008），但兩段方向不一致（2020Q3–2022 為負）、全期 t 都不到 1；四項標準只有「確認樣本同號」成立。
- 中小型股：實際日到期限這段（平均只有約 6 個交易日）就有明顯漂移，第 501–1000 名 t 3.6、第 1001–1500 名 t 3.2，與 I037 的發現一致——利潤率驚奇只在中小型股被慢慢反映。
- **解讀**：I037 在前 500 名不顯著，不是因為「進場太晚」；大型股的季報利潤率資訊在公告時就已被定價，或在公告前就由法說會、月營收與自結資訊揭露。
- 依點子卡停止，不改用毛利率版或換視窗；也不做 fv5 合成。I052（季報公告溢酬）可共用這份公告日資料。
