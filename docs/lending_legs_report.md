# 借券腿（2026-10-13）

腿池第一輪時借券資料已下載、但還沒加入（[leg_pool_report.md](leg_pool_report.md)）。這裡測試 4 條借券腿。
完整自動產生的表格見 [lending_legs_top300.md](lending_legs_top300.md)。研究結果，非投資建議。

## 設計（看結果前固定；方向事先定為「借券／放空越多 → 之後報酬越差」）

| 腿 | 定義 | 依據 |
|---|---|---|
| 借券賣出餘額比 | 前一日借券賣出餘額 ÷ 已發行股數 | 放空部位水準 |
| 借券賣出 20 日增量 | 20 日借券賣出餘額變化 ÷ 已發行股數 | Lin、Ho、Ko 2023（PBFJ）：放空流量預測負報酬 |
| 借券費率 | 前 60 日借券成交量加權費率 | Cohen、Diether、Malloy 2007：借券需求與費率高 → 之後報酬差 |
| 借券需求量 | 20 日借券成交量 ÷ 已發行股數 | 借券需求 |

- **資料來源**：FinMind 免費層的 `TaiwanDailyShortSaleBalances`（借券賣出餘額）與 `TaiwanStockSecuritiesLending`（借券成交）；不需新的 API 呼叫。
- **訊號處理**：固定包裝，即產業內 z → 20 日平均 → 中性化。
- **組合**：fv3 建構，即等權多空、限制可借、每 3 個月換倉、三份資金錯開；扣交易成本與借券費，用台指期對沖。
- **判準**（兩段都要通過）：
  - 與 SUE 合成，要高於 SUE 單獨（0.93 / 1.79）；
  - 與 SUE + 營收創新高三者合成，要高於 1.22 / 2.13。

## 解讀

1. **沒有一條借券腿通過判準**：
   - 合成後 2023–2026 常常變好，例如借券賣出餘額比 + SUE + 營收創新高，2023–2026 從 2.13 升到 2.53；
   - 但 2019–2022 都變差，從 1.22 降到 0.96。
2. **借券賣出餘額比與借券費率的 60 日 IC 在兩段都顯著**（t 3.6–5.6），與 SUE 幾乎不相關（約 +0.05–0.09）；但轉成扣成本的多空組合後，單獨 Sharpe 只有 −0.13 ~ 0.89，2019–2022 都不賺錢。
3. **事後檢查一個解釋，結果不成立**：我原本猜測放空最多的股票借不到，所以放空端拿不到這個效果。
   - 實際上，放空最多的 1/3 中有 81% 借得到，和放空最少的 1/3（82%）相近，只是費率較高（中位數 2.7% vs 0.9%）。
   - 未經產業與市值中性化時，三組的 60 日相對報酬差異只有 ±0.3%。也就是說，IC 來自產業內、市值中性後的排序，但這個排序的報酬差距不足以支付成本，兩段的表現也不一致。
   - 確切原因目前沒有定論。
4. **借券需求量兩段方向相反**：2023 年後借券需求高的股票反而上漲，可能和 AI 多頭期間的避險借券有關，但沒有檢驗。

## 結論

借券腿不採用。借券賣出餘額比在 2023 年後與 SUE 搭配的效果很好，但 2019–2022 變差；在多重比較下，不應依後段表現挑選。若要再試，應事先定義新的用法並在前瞻資料上驗證，例如只作為做多端的負向濾網。
